MongoDB 端口协议（27017）：和数据库说话**不用驱动，协议本身就是话**——
**报文头 16 字节**：长度 int32 / 请求号 int32 / 响应号 int32 / 操作码 int32
（OP_MSG = 2013）；
**OP_MSG 体**：flagBits int32 + 段——段首一个 kind 字节：
kind 0 = 一个 BSON 命令文档，kind 1 = 文档序列（大结果集分块续写，
identifier 指明塞给哪个字段，如 cursor.firstBatch）；
**命令就是一份 BSON 文档**，字段名即命令：{"find": 集合, "filter": {...}, "$db": 库}
——**每个请求自带 $db**，协议里没有「先 use 库」这一步；
**回执也是 BSON**：ok=1 成功、ok=0 失败（errmsg 里是原因、code 里是错号，
13/18 是没权限）；
**只读要先接得住空**：ok=1 但 firstBatch 是空的 ⇒ 账面就是零，**不是连不上**；
连不上（端口拒绝 / 超时）才是故障——不重试，报人。
BSON 类型标记（读回执要看）：0x01 双精度、0x02 字符串、0x03 文档、0x04 数组、
0x07 ObjectId、0x08 布尔、0x09 日期、0x0A 空、0x10 三十二位整数、0x12 六十四位整数。
