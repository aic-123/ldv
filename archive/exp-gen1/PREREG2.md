# 实验二预注册：干扰鲁棒性曲线（写在任何一次 API 调用之前）

按用户设计：固定一组需要跨材料聚合的问题，掺入递增比例的**无关文档**（0%→30%→60%→90%），
**报曲线，不报单点**。实验一/三已确立两条纪律：①默认配置的失效要先补预算再下结论；
②结论只在本模型、本规模内说。

---

## 1 协议

- 模型 `deepseek-flash`，`temperature=0`，与实验一/三同。
- **相关材料固定 250 条论文登记**（OpenAlex 真实切片，与实验一同源）。
- **噪声**：讨论班日程记录（`〔Bxxxx〕讨论班：研读《同一批论文的标题》，20xx 年秋季安排。`）
  —— 同形状、**含年份**（部分 ≤ 阈值年，是陷阱：不区分种类就会收进来）、不同种类。
- 比例（按记录条数）：0% → 30% → 60% → 90%（噪声 = 0 / 107 / 375 / 2250 条）。
  ⚠️ 材料总量随比例增长（17k → ≈105k token）—— 这是设计的固有混淆
  （"掺噪声"必然变大），在结果里注明，不粉饰成纯噪声效应。
- **问题（聚合型）**："列出材料中全部**论文登记**里年份 ≤ T 的论文 id。"（T 使答案约 30 条，
  只与相关材料有关，噪声加多少都不变 —— ground truth 稳定。）
- 三组：A 全塞窗口（**默认配置**：非思考、输出 16k —— 与实验一默认档同，标签如实）；
  B 字面检索 top-8；C 结构查询（`type=论文` 的全部节点，脚本侧按 `year=` 键过滤 —— 机制作答，0 token）。
- N=2 seed × 4 比例。指标：**集合 F1**（对 id 集合算 recall/precision/F1）。

## 2 证伪条件

- **F1**：若 A 在 90% 档 F1 ≥ 0.8，则「噪声淹没聚合」在本设置不成立——曲线照报，结论如实。
- **F2**：若 B 在全部档位 F1 ≥ 0.8（检索对噪声鲁棒），同理如实报。
- **F3**：C 任何一档不是精确解 ⇒ 记「机制未覆盖」，不记满分。
- 与实验一相同：A 输出若 `finish=length`（截断），该次**作废重跑**（输出预算给足 16k，
  答案只有 ~30 个 id，正常不应触顶）。

## 3 成本上限

A 组 8 次调用（最大单次 ≈105k 输入）+ B 组 24 次小调用 ≈ **¥1.5 以内**。
