# 仓库资产分级（2026-11-02 定）

> 目的：让「哪些是正式资产、哪些是历史记录」一眼可辨。
> 分级不是清仓 —— **每一类都保留**，只是各归其位、各守其规。

## 分级总表

| 类型 | 处理方式 | 位置 | 守护 |
|---|---|---|---|
| **正式测试** | 保留在测试目录 | `ldv/tests/`（`run_tests` 934 条）· `ldv/checks/`（`run_checks` 97 断言） | CI / 本地判据，红即失败 |
| **可复现研究实验** | 保留，**统一入口 = [`exp/INDEX.md`](../exp/INDEX.md)** | `exp/`（E1–E4 · m0 · m1 · m2 及其预注册/结果/脚本） | 预注册先于数据；判分脚本 sha256 冻结 |
| **关键原始证据** | 归档，**保持不可变** | `evidence/`（166 件，逐件被文档引用）· `exp/runs/`（逐次调用原始 jsonl，只增不改） | `evidence_index check`（无悬空引用/无孤儿）+ `quote_index` 判据 |
| **一次性探针** | 转入历史归档 | `archive/one-off-probes/`（新增的一律进这里，不再进 `evidence/`） | 无守护（历史记录，不进判据） |
| **临时输出** | 不再作为正式仓库资产 | 不入库（`.gitignore`）；已入库的历史输出随其证据文档留在 `evidence/` | — |

## 分级时定下的三条规则

1. **`evidence/` 不再做增量。** 它是「被文档引用的不可变证据库」，由
   `ldv/tools/evidence_index.py` 守着（每个文件至少被一处引用、无悬空、无孤儿）。
   里面有一部分**一次性探针**——但它们已被文档引用、构成证据链的一环，
   搬移需要同步改写引用文档，得不偿失 ⇒ **留原地，冻结增量**。
   此后新探针、新测量脚本一律进 `archive/one-off-probes/`（或实验目录），
   不再享有「证据实体」地位，除非被正式文档引用并走 `evidence_index` 登记。
2. **实验以「代」分，不按时间删。** 第一代非预注册实验（`archive/exp-gen1/`，
   2026-10-29 之前）保留原文，但其结论一律以 E1–E4 预注册系列为准；
   两代结论冲突时，**预注册版赢**。
3. **原始数据不可变。** `exp/runs/*.jsonl` 逐次调用一条记录，**只增不改**；
   作废数据不删除，在预注册文件里记「作废 + 原因」（先例：V7 首轮、V10 首轮、
   V11 首轮、E4 初版试点）。
