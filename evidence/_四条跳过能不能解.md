**问题**：用户要的不是「发现 + 标注」，是**把这些跳过解决掉**。
**做法**：逐条找「它在什么配置下有内容」，并在**真语料**上实测；对「强行判」的后果也做了**反向判据**。

## §1 `B20` ×2：**不该解** —— 解了就是造一条「常驻的过」

### 1.1 为什么它在这两条轴上没内容

`B20` 问的是「反复声称能分、却连续 N 次**在标签上**什么都没分开」。
`label_bearing` 的判据是「标签的**取值键**（`type=<值>`）在不在这条方向的**键空间**里」：

    keyset    split 按**键**切，而 `type=<值>` 就是一个键 ⇒ 这条轴**能**按标签切
    reach     split 按**可达性签名**切 ⇒ 标签不在它的键空间里
    sequence  split 按**前缀**切      ⇒ 同上

### 1.2 强行判会怎样（实测）

`outputs/_probe_skip_forced.py`（monkeypatch `label_bearing` 恒 True）：

    默认 36 项：  keyset 12 展开/空转 5/最长段 3 ⇒ 过 ｜ reach 35/10/2 ⇒ 过 ｜ sequence 5/0/0 ⇒ 过
                 汇总：断言 97 条：红 0，**跳过 4 → 2**

看着像是「解掉了两条」。**但下面这一步把它否掉了。**

### 1.3 ★ 反向判据：把标签**随机重排**之后，它**还是过**

`outputs/_probe_b20_false_red.py` —— 把 `type` 的取值**随机打乱**（与结构彻底无关，
正是 `test_injections` 给 `B20` 做注入时用的同一招），同时强行判：

    reach     35 展开/空转 4/最长段 1 ⇒ **过**
    sequence   5 展开/空转 0/最长段 0 ⇒ **过**
    keyset    12 展开/空转 0/最长段 0 ⇒ **过**
    汇总：断言 97 条：红 0，跳过 2

**标签已经与结构彻底无关了，它照样过** ⇒ 这条轴上 `B20` **红不了**。
⇒ 判它得到的那个「过」**不是读数**，是一条**永远绿的判据**。

    「一条常驻的红等于没人再看红」   ← 本仓库记过两次
    「一条常驻的过等于这条判据在骗你」 ← 同一条道理的**镜像**

⇒ **跳过是对的**：它现在做的正是「说清这条轴上没有内容」。把它改成「过」，
就是把「没有内容的过」与「有内容的过」**混成同一个样子** —— 正是本仓库一直在防的形状。

## §2 `B17` @ `reach`：**能解，但不是判据的毛病，是语料的**

`B17` 的跳过条件是**纯语料性质**：等价类 = 「互相可达」（对**任何** payload 同进同出）
⇒ **无环图（DAG）上只有自身** ⇒ 全单点 ⇒ 退化。

`outputs/_probe_b17_across_corpora.py` 把仓库里 13 份语料全扫了一遍（只算等价类，秒级）：

| 语料 | 项 | `reach` 最大等价类 | `B17`@reach |
|---|---|---|---|
| **默认 36 项** | 36 | **1** | 跳过（全单点） |
| snap-hepth | 1200 | **51** | ★ **判得了** |
| **snap-hepth-dag** | 1200 | **1** | 跳过（全单点） |
| snap-email-eu-mini | 120 | **114** | ★ **判得了** |
| snap-email-eu-mid | 300 | **286** | ★ **判得了** |
| openalex-citations | 3907 | **497** | ★ **判得了** |
| pypi-deps | 60 | **7** | ★ **判得了** |
| arxiv-taxonomy / crossref-journals / gh-langs / edge-* | — | 1 | 跳过（全单点） |

★ **`snap-hepth` 与 `snap-hepth-dag` 是同一张图的「留环 / 去环」一对** ——
这正是当初（commit ⑪）造它们的目的：给「`B17` 缺口 == 环」补上**单变量对照**。

⇒ **解法**：把 `B17` 配到**有环语料**上跑（配置问题），而不是改判据。
   在默认语料那趟里，`reach` 上它**原理上**就没有内容。

## §3 `A5` @ 视图：★ **这条是真缺口 —— 它在生产上从来没判过**

`A5` 判「视图账里的每一条都指得到方向 + 项，且独立重算下成立」。
账 = **滞留**（`§10.2` 出路 (4)）+ **根覆盖之外**（出路 (1)）。

`outputs/_probe_skip_solvable.py`，跨 6 份语料 × 3 方向 × 2 路径：

| 语料 | `keyset` 批建 | `keyset` 维护 | `reach` 维护 | `sequence` 维护 |
|---|---|---|---|---|
| 默认 36 项 | 0 / 0 | 0 / 0 | 0 / **28** | **16** / 0 |
| gh-langs | 0 / 0 | 0 / 0 | 0 / **50** | 0 / 0 |
| crossref-journals | 0 / 0 | 0 / 0 | 0 / **68** | 0 / 0 |
| pypi-deps | 0 / 0 | 0 / 0 | 0 / **23** | **34** / 0 |
| arxiv-taxonomy | 0 / 0 | 0 / 0 | 0 / **130** | **6** / 0 |
| edge-tiny | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |

（格子里是「滞留 / 根覆盖之外」）

**两条硬事实：**

1. **`keyset` 的账恒空** —— 批建与维护**都是 0/0**，跨 6 份语料无一例外。
   原因：`keyset` 是**精确切分**（键要么匹配要么不匹配）⇒ 没有滞留、没有根覆盖之外。
2. **14 份 `view_spec.json` 全部声明 `方向=keyset`**（逐份查过）。

⇒ 两条一合：**`A5` 在 `reach` / `sequence` 的维护路径上判得了（28 / 50 / 68 / 23 / 130 …），
但视图层跑的是声明里的 `keyset` ⇒ 它一次都没判过。**

这不是「本趟没内容」，是**这份声明让这条判据永远没内容**。

## §4 解法（三条，分别对应）

### 4.1 `B20` ×2 —— **不解**，保持跳过

理由见 §1.3（随机重排后仍为过）。要真解，得先能构造出「这条轴上 B20 会红」的语料 ——
而那不是修判据，是**造一份标注与结构正交的语料**（`test_injections` 已经这么干过，
用的是「每刀 50/50」的指派）。**在生产语料上它没有内容。**

### 4.2 `B17` —— **配到有环语料上跑**

仓库自带 5 份有环语料，且 `snap-hepth` / `snap-hepth-dag` 是现成的**单变量对照**。
做法是把 `B17`@`reach` 也放到那两份语料上跑一趟，把「跳过」变成**真判**。

### 4.3 `A5` —— **要你拍板一处外生决定**

`A5` 要真判，视图层必须跑在**账非空的方向**上 —— 即 `reach` 或 `sequence`
（且要**维护路径**）。而「视图层用哪个方向」是**外生声明**（`view_spec.json` 的 `方向`），
设计稿 §10 停止条件 1 明说：**`P` / `E` 必须外生，猜一个就是替人做 `§K9` 的决定**。

⇒ **我不能替你选**。可选的三条路：

    (a) 把 `view_spec.json` 的 `方向` 改成 `reach` 或 `sequence` —— 视图层的含义随之变；
    (b) 保留 `keyset`，但让视图层**同时**在维护路径上跑一趟，把 `A5` 的跳过理由写成
        「本声明（精确切分）让账恒空」—— 即把「跳过」说得更准，而不是消除它；
    (c) 维持现状（跳过 + 合成对照）—— 并**如实记着 `A5` 至今没在生产上判过**。
