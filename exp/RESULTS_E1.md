## 3 两个计划外发现

### 3.1 取回税（R-L 末段下滑的归因）

R-L 末段 7 个低分任务全部同形状：工具轮 2（orient → ask 规则）、finish=stop、
报 0–1 对就交卷。已排除执行器问题（手动重放 `ask require=["type=规则"] with_body=true`
确认规则全文正常返回）。**B-0 无规则反而扫全量报 20–40 对**——"取回动作本身"让模型
提前收工，且取回的规则位于上下文最前、离材料最远。对照：R-R 的规则紧贴材料，无此现象。
⇒ **结构记忆的代价不是 token，是"查过了"的心理完成感**。

### 3.2 自条件化放大器（L-0 为什么平坦、L-L 为什么满分）

- L-0（0.495）**高于** R-0（0.319）且压缩前后无变化：累积历史里模型**自己的早期输出**
  充当隐性 schema——短引导被压缩掉之后，它仍在模仿自己。预注册 §0 的备择解释被数据证实。
- L-L 满分的机制要拆开说：任务 2–12 靠窗内长引导；**任务 13–15（引导已被压缩掉、
  工具轮均 0、一次工具都没调）依旧满分**——靠的是此前 12 份完美输出构成的自我示范。
  ⚠️ 诚实表述：**L-L 没有直接行使"从结构取回"的通道**（那是 R-L 在做的事，且有取回税）。
  L-L 的完美 = 开局规则在窗 + 自条件化保持。两组合起来才是完整结论：
  **结构的真正价值在"开局即正确"，而不是"每次取回"。**

## 5 限制条件（必须跟结论一起出现）

1. 单模型（deepseek-flash，1M 窗）；
2. 单任务 ≤30.5k token、L 组累计 ≤150k（"长上下文"是**累计意义**上的，不是单窗 100k+）;
3. 15 任务、15–88k 字爬坡、矛盾 k=5 固定；
4. R-L 的"替代成立"带**末段失效**限定（比值 0.72）；
5. L-L 的满分含自条件化贡献（工具通道未被行使）；
6. 压缩为确定性摘要行，非 LLM 摘要——真实 compaction 的行为可能不同。

### 方向性结论（限制条件：免费小模型 · 方差大 · 部分 run 截断）

1. **"引导丢失崩塌"跨模型方向一致**：R-R ≫ R-0 在两个模型上都成立
   （deepseek 0.987/0.319 = 3.1×；flash 0.356/0.117 = 3.0×）——比值几乎相同。
2. **弱模型上长会话裸奔更惨**：L-0 全零 vs deepseek 0.495——"自条件化"
   （模仿自己早期输出）是强模型行为，flash 无此红利。
3. **工具循环协议有模型门槛**：flash 无法完成 R-L/L-L 协议（tool_exhausted
   率 88%）——"引导进结构"的可行性以下限模型能力为界，与 E1 主表
   "结构记忆在所有模型上可用"不成立的记录互证。
4. 已知缺陷：flash 记录的 usage 记账全 0（短输入实测正常，长输入疑网关
   不返回 usage），GLM 批次成本以任务数×估算 token 计，未入 API 账单实测。
