# V17 会话材料包（约 20–30 分钟）

被试：库主人本人。材料：本页 + 需求卡 8 张（剪开、随机顺序）+ 录音工具。
全程用 `CORPUS_CARD.md` 的 120 条（打印或屏幕），**不要打开任何树/链视图**。

---

## A. 给被试的开场白（照读）

> 我接下来会请你找 8 次东西，都是这份 120 条记录里的。
> 重要的是：**找的过程中，嘴里要一直说你正在想什么**——比如「我先看看有哪些类别的」、
> 「这条不对，跳过」——想到什么说什么，不用组织语言，也不用解释为什么。
> 说错了也没关系，我不会打断你。如果停下来超过一会儿，我会提醒你继续说。
> 现在先练习一下：请出声说说，你今天早上出门前是怎么决定穿什么的。

（练习 2 分钟后开始正式任务。）

## B. 需求卡（剪开，随机顺序呈现，一次一张）

```
1. 把里面标过重要的书找出来。
2. 练背的记录有哪几条？
3. 口味清淡的食谱是哪条？
4. 适合夏天去的旅行是哪几条？
5. 固定支出有哪些？
6. 还没修好的报修有哪些？
7. 6 个人的那场会议是哪场？
8. 发表在 NeurIPS 的论文是哪篇？
```

每题：翻需求卡 → 开始出声 → 找到答案（说出条目名）→ 停录音换下一张。
**被试看不到对应谓词；谓词对照表只在判分时用（见 PREREG_V17 §1）。**

## C. 转写格式

```
[C1-段01] 我先看看……（原文逐字）
[C1-段02] ……
```

- 段的边界 = 停顿处；一段一个主码。
- 「15 秒提醒」事件要记：`[C3-提醒] （停 18s）请继续说你在想什么`。

## D. 编码表（会话后填）

| 段号 | 主码（I/F/S/P/V） | 字段维度（F 码才填） | 原文（逐字） | 备注 |
|---|---|---|---|---|
| C1-01 | | | | |

码定义见 `PREREG_V17.md` §3。**主码=该段最主要的一个动作**；
一段里先「只看书」后「挑重要的」算一段 F（字段=type+标记合并叙述时记 F，
字段列写 `type,标记`）。
