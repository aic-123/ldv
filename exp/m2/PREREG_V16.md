# PREREG：字段折叠呈现（V16，2026-11-02 18:26，先于任何 V16 数据）

> 依据 `STOP_PROBE.md` §7：链长 5–10 vs 人 3–4 的差，是**讲述单位**问题
> （二元步 vs 字段决策），不是 LDV 想得深（相干字段恒为 2）。
> 修复方向：呈现层**按字段折叠**——同一字段的连续切分合并成一步。

## 1. 折叠规则（写死）

对 `chain_of()` 的步骤序列（跳过根）从左到右扫描：

| 情形 | 处理 |
|---|---|
| 连续 ≥1 步的 `切` 都是**同一字段**（如 `type◆→type◆→type◆`） | 合并成 1 步：「按 `type` 筛选（3 刀）」，成员数取该段**最后一步**的成员数 |
| `切` 为 None（子方向细分，无谓词变化，如 `title·`） | 记为**过路步**单独保留（它是"还有子类"的信息，折叠掉会丢） |
| 字段变化 | 开启新的一段 |

**验收不变式（机械，写死）**：

| ID | 不变式 |
|---|---|
| **M1** | 折叠版的**相干字段序列**与原版逐字相同（折叠不改决策内容） |
| **M2** | 折叠版最后的成员数 == 原版最后的成员数（答案支不变） |
| **M3** | 折叠版步数 < 原版步数（凡原版有同字段连续切分处） |
| **M4** | 过路步**不折叠进字段步**（保留"这里只是子类细分"的信息） |

## 2. 盲判（V15 契约：依据逐字、结论可归纳、无证据必弃答）

呈现：同一需求的**原版链**与**折叠版链**（分开问，不并排对比——避免"并排找差异"替代理解）。

问法：「这个过程**实际用了哪几个字段**做筛选？**分几步**？」

**真实答案（机械可算，判分基准）**：
- 字段集合 = 链上**相干步**的字段集合（`ROLES.md` §4.1 的定义）
- 步数 = 折叠版的步数（字段决策数），**不是**原版的二元步数

| ID | 判据 | 阈值 |
|---|---|---|
| **F1** | 折叠版：agent 报的字段集合 == 真实相干字段集合 | ≥4/5 需求 |
| **F2** | 原版：同上 | ≥4/5 需求 |
| **F3** | 折叠版：agent 报的步数 == 折叠步数（±0） | ≥4/5 需求 |
| **F4** | 原版：agent 报的步数是否被二元步数误导（报 5–6） | 记录项 |

**样本**：C1–C8 全部 8 条需求 × 2 呈现 × 3 实例 = **48 次调用**（每需求内实例间顺序不构成对照，直接 3 次重复测稳定性）。

## 3. 判读（先写死）

- **F1∧F3 过** ⇒ 折叠版让 agent **准确复述**筛选过程（字段对、步数对）
- **F1 过、F2 红** ⇒ 原版会**误导**字段提取（二元步被当成多个筛选）⇒ 折叠有理解收益
- **F1∧F2 都过** ⇒ 折叠的收益只是"短"，理解层无差别 ⇒ 如实写
- **F1 红** ⇒ 连折叠版都复述不准 ⇒ 呈现层路线暂封，回结构层
- 每需求 3 实例的报数**多数票**为准；3 实例互相不一致 ⇒ 记"不稳定"，不计入判定

## 4. 不许做的事

- ❌ 不许并排给两版让 agent 比较找差异（那是找不同，不是理解）
- ❌ 不许在 prompt 里出现"折叠/合并/压缩"等暗示词
- ❌ 机械验收 M1–M4 有一处不过 ⇒ 修折叠实现，**重新跑机械验收**，盲判作废重跑

## V16.1 增补（机械验收 M3/M4 定义错误，写于修正重跑之前）

首轮机械验收 M4 全红、M3 部分红。读数追因：**折叠实现无错，是验收定义写错了**。

1. **M4 错在把两种"过路"混为一谈**：原版 `cut=None`（子方向细分）只是过路的一种；
   另一种是"切了非需求字段"（如 `标记·`——字段存在、有谓词，但与本次需求无关）。
   折叠版把第二种也标为过路（`ROLES.md` 的过路定义：与本次问题无关），是**正确行为**。
   用 `原版 cut=None 计数 == 折叠版过路计数` 做检查，两者天然不等。
2. **M3 错在要求恒变短**：C7 的链是 `标记· → type◆ → 参会◆`，三个字段互不相同，
   没有可折叠的同字段连续段 ⇒ 步数不变是**正确结果**。

**修正（只改验收定义，折叠实现一字不动）**：

| ID | 修正后 |
|---|---|
| **M3′** | 折叠步数 ≤ 原步数；且**凡原版存在同字段连续 ≥2 刀的段，折叠步数必须严格变短** |
| **M4′** | **无信息增发**：折叠版出现过的字段 ⊆ 原版出现过的字段；原版相干字段无一遗漏（与 M1 互补：M1 管序列，M4′ 管集合与无增发） |

M1/M2 不变。修正后重跑机械验收；盲判未跑，不受影响。
