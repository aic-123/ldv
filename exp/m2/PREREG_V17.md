## 0. 动机与被替换的量

`stop_v1.py` / `chains.json` 里的 `HUMAN_STEPS`（人 3–4 步）是**事后追述**，
Ericsson & Simon 明确指出追述会变成"合理化的故事"。V17 用**并发出声思维**
（concurrent protocol）重测，得到权威口径的人侧数据。

## 2. 会话纪律（Ericsson & Simon，逐条执行）

1. **预训练** 2 分钟：用一道无关小事（"说说你今天怎么挑的穿的衣服"）练习出声。
2. **并发**：边找边说，想到什么说什么；不许事后补述。
3. **不打断**：停顿 >15 秒只提醒「请继续说你在想什么」，不提示方法。
4. **不提示**：全程不得出现"分类/字段/层级/第一刀/树"等词。
5. 录音（或现场逐字记录）；每题之间停录音。

## 3. 编码（会话后进行，逐段）

转写后按停顿分段，每段编一个主码：

| 码 | 定义 | 例 |
|---|---|---|
| **I 意愿** | 说出目标/偏好，不含具体字段 | 「我想找重要的」 |
| **F 字段决策** | 明确按某个维度收窄 | 「先只看书」「在这几条里挑重要的」 |
| **S 扫描** | 逐条看内容，无维度声明 | 「这条不是……这条是」 |
| **P 过路/跳读** | 声明跳过某块 | 「食谱先跳过」 |
| **V 验证** | 确认答案 | 「就是这两条」 |

**主判据量 = F 码的个数（去重后的字段维度数）**，与 LDV 的相干字段数对照。

## 4. 判据（先写死）

| ID | 判据 | 依据 |
|---|---|---|
| **H1** | 真人 F 码的**字段序列** 与 LDV 链的相干字段序列一致（同为 `type→需求字段` 或包含关系）≥ 7/8 需求 | Rosch 基本层级（P-R1/P-R2）+ STOP_PROBE §7 |
| **H2** | 真人 F 码数（去重维度）在 **1–3** 之间，均值 ≤ 2.5；与 LDV 相干字段数（=2）差 ≤1 的需求 ≥ 7/8 | Eluchans 2025（最小必需深度）+ V15/V16 实测 |
| **H3** | 真人 S+P（扫描+跳读）段的**比例** 显著低于 LDV 链中过路步占比（文献预期：人靠类别归组跳读，不逐条扫全库） | Bergman 2010（类别归组导航） |
| **H4（记录项）** | I 码出现次数（意愿步）——预期 8/8 需求至少 1 次，而 LDV 链为 0（结构里无意图槽） | E2/E4 结论 |

## 5. 判读

- **H1∧H2 过** ⇒ 「LDV 的思考形状与人一致、差在讲述单位」从实验证据升级为
  **行为级+文献级双重确认**；`HUMAN_STEPS` 表被 H2 的实测值替换。
- H1 红而 H2 过 ⇒ 字段选择不同但深度相同 ⇒ 重新定性为"形状一致、路径不同"。
- H2 红（真人 F 码 > 3）⇒ Rosch/最小必需深度先验不适用于此语料，
  STOP_PROBE §7 的结论须加"仅在 120 条小库"限制。
- H4 若真人也无 I 码 ⇒ "意愿步归 agent"的说法降级为"agent 提问方式所致"。

## 6. 不许做的事

- 不许用 agent 扮演被试（R1 不可替代）。
- 不许在会话中给被试看任何树/链/字段名。
- 不许因为读数不符合 H1/H2 而重开会话换措辞。
- 编码由会话记录者之外的一人复核（同一人也可，但须先分段后编码，
  编码表随结果一起归档）。
