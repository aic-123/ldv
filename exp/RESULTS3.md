## 2 诚实账目

- 三问调用落盘用量合计 **¥0.07**（前缀缓存命中率 99.8%：359k 输入里 miss 只有几百 token）；
  灌水确认轮的用量未逐轮落盘，估算实验三总花费 **≈¥1.5**。
- A 的代价在**延迟**：三问一次 150–300 秒（359k 档）；C 是 0.1 秒。
- 合成干草堆的 359k 档只是"补长"：被追踪的剧情（R0/R1）始终是真实论文。

## 3 为什么预期错了（写给下一篇的教训）

1. **更正的位置我原以为要"滑出窗口"**——但 359k ≪ 1M 窗口，根本没滑出去。要测"滑出"得先逼近窗口上限，而那已经超出本实验的成本/时间预算（单次三问 300 秒，逼近 1M 时不排除 429/超时）。
2. **lost-in-the-middle 的已知失效带**主要出现在"多事实检索/聚合"，不是"时序事件的记忆"——会话中的事件序列有强时序线索（第几轮说的），模型沿对话轴回忆比沿材料轴检索容易得多。
3. 实验一的教训在这里重演了一次：**"看起来完美的默认失效"大多是预算问题**。这次连补测的机会都没给对手留——直接全对。

## 4 两个实验合起来，**能**主张什么

| 主张 | 证据 | 强度 |
|---|---|---|
| **召回可以买，精度买不回** | 实验一：默认 k=40 召回 0.01，思考+96k 买回到 0.975；**但 k=0 的凭空误报反而 10→28**。精度随规模崩且加钱更糟。C 全档 precision=1.00 | ★ 可作为主论点 |
| **A 会在"没有矛盾"的材料里捏造矛盾** | 实验一 k=0：97k 材料 3/3 次各报 10 条，10/10 命中同值陷阱（它没比对年份，把重复当矛盾）；C 报 0 | ★ 支撑上一条 |
| **中密度不稳定** | 实验一 k=20：0.95 / 0.05 / 0.90（同配置三次）——不可复现本身就是故障模式 | ★★ 需更多 N |
| **覆写式 RAG 丢历史，追加式不丢** | 实验三 B：overwrite 丢 1 次（Q2），append 全对 | ★ 样本小（2 seed），只够说"取决于索引策略" |
| **C 的优势是经济性与确定性** | 0 token / 0.1s / 零方差 vs A 每问 150–300s + 数十万 token | ★★ 规模越大越甚 |
| ~~长上下文结构性失效~~ | **两个实验都没能确立**（在 ≤359k、此模型上） | ✗ 撤回 |

**后续（实验二）**：干扰鲁棒性曲线是三条里唯一按预期方向成立的——A 的 F1 随噪声单调下滑
（0.936→0.470），且失效**全部集中在精度**（召回 0.956→0.853 几乎不掉，精度 0.918→0.413 崩半），
与「召回可以买，精度买不回」同族；C 平坦 1.0。见 [`RESULTS2.md`](RESULTS2.md)。成本曲线见 [`RESULTS4.md`](RESULTS4.md)。

## 5 边界（写进文章的"我们没测什么"）

一个模型（deepseek-flash，1M 窗口）· 最多 359k token（1M 的 36%）· 单次修正事件（无多次反复）·
无跨天间隔 · 干草堆部分合成 · 2 seed（中埋 359k 档）。**窗口上限 30% 以内、单次修正、此模型**——
这三个限定语必须跟着结论走。
