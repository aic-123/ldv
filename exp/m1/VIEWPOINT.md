被测：内核 `ldv` @ `291dad5`（v0.1.52）｜语料：`openalex-citations`（4037 节点 / 77 方向）
判据：`exp/m1/PREREG.md`（sha `e44f6ce9…`，V2 `905f3a1f…`，均先于数据）

**一句话结论：结构化 ✓、独立 ✗、可累积 △、视角 ✗ —— 它是「可审计的索引 + 组合谓词中间层」，不是"独立的结构化视角"。**

**结论：不成立（部分）**。机制层成立的部分很硬——结构非随机、对意图敏感、存在材料字段之外的组合谓词中间层（Jaccard 0.01 而非凑到 0.95）。

1. 本语料的键是**互斥且穷尽**的（`type` 的 6 个值覆盖全部 4037 项），因此每个方向的 `forb` 必然列出全部兄弟值 —— 这是"全维度枚举"的算术来源。若材料键稀疏（大量项缺键），`forb` 不会膨胀，S3-4 可能不同，**未测**。
2. S3 的判据"顶层含 X 谓词即对齐"由我们自己定义；V1 的结果（下节）正好否定了这一判据的可辨识性。

### V11：视角可由 ldv **自己输出**——纯事实、零分数、不依赖排序

**动机**（用户 2026-11-01 17:52）：抽象层**由方向树直接生成，只有方向树变化才引起抽象层变化**
⇒ 使用记录进不了抽象层（`views.py` 自述 + §K9/`B14`）；而协议层
`BANNED_FIELDS = ("score","weight","priority","rating")` 又禁止输出权重数值。
V10 能读出"重视什么"，靠的是执行者绕过接口直读 `_tendency` —— 那还是把视角压在 agent 上。
**V11 问：把权重换成纯事实，视角还读得出来吗？**

**呈现件（零分数）**：每行只给 `谓词 ｜ 项数 ｜ 使用 N 次 ｜ 最近 X 天前`；
prompt 只说明两条公开机制（「只有下钻才留记录」「记录随年龄衰减，半衰期 30 天」）。

**构造**：6 支被 drill，其中 **只有 B（`type=review`）是 0 天前**，A（`type=article`）与
另 4 支均为 300 天前。四组各 5 实例（共 20 次调用）：

| 组 | 呈现 | 结果 |
|---|---|---|
| **P1** F1 真 | 事实 + **真实顺序** | **5/5 指出 review** |
| **P2** F1 伪 | 把"最近使用"在 A/B 间**对调** | **5/5 改口说 article** |
| **P3** F2 真 | 事实 + **顺序打乱**（标题注明"顺序无意义"） | **5/5 指出 review** |
| **P4** F2 伪 | 对调 + 顺序打乱 | **5/5 改口说 article** |

> 判分说明：首判 P3 为 0/5，追因为 judge 缺陷——review 方向的谓词本身含 `¬(type=article)`，
> 模型写「review（非 article）」被判成"指向 article"。按 PREREG V11.3 识别否定形式后
> **用同一批原话离线重判**（未重新调用模型），两套读数都保留
> （`v_facts/result.json` / `result_rejudge.json`）。

模型原话（F2 真件，顺序已打乱）：

> 「更重视『2020 年以前、同行评审的 review（且非 article）』这一类方向。依据是它的使用记录
> 最近为 **0 天前**，而其余有使用记录的方向最近都在 **300 天前**；按 **30 天半衰期** 衰减，
> 0 天前的权重远高于 300 天前（约衰减为 1/1024），因此当前权重几乎全部集中在这一类。」

#### 三条结论

1. **视角可以不由 agent 承载**：agent 只做措辞——它给出的依据全部是 ldv 输出的数字
   （次数、天数），并且**自己按公开半衰期算出了比值**。它没有"猜重要什么"，是"算出来的"。
2. **不依赖排序**：F2 把顺序完全打乱仍 5/5 ⇒ 视角在**事实**里，不在"谁排第一"里。
   这比 V10 更强：V10 只能证明"排序+权重可读"，V11 证明"事实可读"。
3. **不需要输出任何分数**：`n_records` / `last_used_days` / `half_life_days` 都是事实，
   不撞 `BANNED_FIELDS`；也不动抽象层的 `P`/`E`，不撞 §K9/`B14`。

#### 对"抽象层能不能做到"的直接回答

**做不到，而且不该由它做。** 抽象层的输入只有方向树（用户裁定 + `views.py` 自述），
它的职责是"对结构的一份认识、不随时间漂移"。使用记录驱动的视图会让 S1（可复现）当场红。

**能做到的是检索层的输出契约**：现在 `query` 只回 `ordered_by="usage"` 一个词，
读者被迫从"谁排第一"反推 —— 视角才被挤到 agent 那边。把这一词换成
**注意力事实清单**即可：

```json
"attention": {
  "half_life_days": 30,
  "rows": [{"did": "D7", "n_records": 1, "last_used_days": 0}, ...]
}
```

字段名全部避开 `score/weight/priority/rating`；不含排名、不含分数。
**ldv 说出"我最近用过什么、多久以前"，读的人自己算"这算不算重视"** ——
判断权仍在人/agent，但**素材不再需要猜**。

#### 限制

1. 单模型（deepseek-chat）· 每组 5 实例 · 单一对照（article vs review）。
2. 事实清单只含**前 10 支**（真实查询会返回 39 支），未测长清单下的表现。
3. 「读对」用关键词判分（识别 `非 article` 等否定形式），非语义判分。
4. 仍未测"**用这份事实做决策**"（V10 遗留的同一个缺口）：读出 ≠ 据此改变行为。


### V12：注意力事实能否改变**决策**——成立，但只有一组是"纯"证据

**设计**（PREREG V12）：同一批 10 个候选、**同一顺序**（与使用无关，seed 固定）、
同一个问题——「用户说：我没时间全看，帮我挑**一个**最值得先深入的方向」。
唯一变量是每行的**使用记录**。四组各 5 实例：

| 组 | 使用事实 | 期望 | 实测 | 判据 |
|---|---|---|---|---|
| **G1** | review（537 项）= 0 天前 | review | **5/5 review** | Q1 ✓ **但不可采信** |
| **G2** | article（2803 项）= 0 天前 | article | **5/5 article** | Q2 ✓ |
| **G3** | 全部「从未使用」 | 项数最多的 article | **5/5 review** | **Q3 ✗（红）** |
| **G4** | 一个 **2 项**的方向 = 0 天前 | that tiny | **5/5 tiny** | Q4 ✓（≥3） |

#### Q3 红，暴露的是我的预期错了（不是实现错了）

G3（无任何使用记录）实测 5/5 选 **review（537 项）**，而不是项数最多的 article（2803 项）。
原话：

> 「第 5 项：**唯一规模大、主题明确**（2020 年以前、同行评审的综述），且没有与 article
> 类型重叠的方向，最适合作为优先深入的总览入口。其余方向要么规模太小，要么是 article 子集。」

⇒ agent 的**默认偏好不是"规模最大"，而是"主题明确、规模适中"**。我在 PREREG 里把
"默认 = 选最大"写死了，这条预期错了（另一处：位置效应被排除——四组无一组恒选第 1 行）。

**后果（严格按预注册）**：**G1 的 5/5 作废**——事实与默认偏好同向（review 恰好既是
"主题明确"又是"最近"），两者不可分离，不能作为证据。同理 G2 里的 article 也是"规模最大"，
与"事实最近"同向，说服力被削弱。

#### 唯一的"纯"证据是 G4：2 项 vs 2803 项

G4 把"最近使用"给了一个**只有 2 项**的方向，其余（含 537 项的 review、2803 项的 article）
全是 300 天前。**规模差 1400 倍、主题明确性也最差**，事实与两个默认偏好**同时相反**，结果：

> 「我会先选第 8 个方向。它**最近 0 天前刚被下钻过**，使用记录没有衰减，说明这是当前最"热"
> 的入口；**虽然只有 2 项**，但正适合先快速深入确认价值。」

5/5 一致。**注意力事实压过了 1400 倍的规模差。**

#### 结论

- **注意力事实进入了行动**：G2（推翻默认偏好）与 G4（推翻规模直觉）都成立，
  其中 G4 是唯一与两种默认偏好**同时冲突**的组，因此是决定性证据。
- **G1 不能作为证据**（与默认同向）；**Q3 红是判据预期错误**，如实保留。
- 这也回答了 V10/V11 留下的缺口："读出 ≠ 据此行动"——**这次它据此行动了**，
  且理由完全引用 ldv 输出的事实（"0 天前""未衰减"）。

#### 限制

1. 单模型 · 每组 5 实例 · 单一材料（openalex 前 10 支）。
2. G4 是极端构造（2 项），只证明"能压过规模"，未测"多信号并存时的权衡"。
3. 决策任务只有一种（挑一个先看），未测"排序三个""放弃一个"等形态。
4. 读数依赖 agent 自报 `pick_index`；已用序号反查 did 交叉核对，未出现不一致。

## 机制归因：为什么会这样（读代码，不是推测）

三条硬规则共同决定了本阶段的全部读数，位置：`ldv/plugins/keyset.py`。

### ① 分裂选键只看信息量，不看意图（L176）

```python
best = min(candidates, key=lambda k: (abs(counts.get(k, 0) / n - 0.5), k))
```

每层挑"出现率最接近 1/2"的键二分。**没有任何参数把 `query.require`（意图）传进来**——
树形是"信息论最优二叉树"，与人的意图无关。⇒ `require` 只决定"从哪支进入"，
不改变"每支继续按所有键分叉"（S3-4 顶层的直接来源）。

### ② 谓词单调继承，`common` 不许进来（L180）

```python
return ((p_req | {best}, p_forb), (p_req, p_forb | {best}))
```

`req(子) ⊇ req(父)`、`forb(子) ⊇ forb(父)`。每条路径每层加一个键（正向或负向），
到 rank 16 时 `forb` 已累积 14 项。⇒ 每个方向的谓词必然写成
`a ∧ b ∧ c ∧ ¬(d ∨ e ∨ f ∨ …)` 这种**全维度排除链**——这正是 V3 里
模型判它"最像机械生成"的形态来源；也是 S4 的"组合谓词"（Jaccard 0.01）的来源：
组合不是设计出来的"视角"，是二分递归的副产品。

### ③ 覆盖性要求把"像人"这条路堵上了（L91-104 的注释）

> 子方向的 payload 必须盖住**父方向的整个覆盖**，而不是「当前这批成员」。
> ⇒ 否则一定有项落进「它不满足」的方向 ⇒ `members(d) ⊄ 覆盖(d)` ⇒ 假阴（§K8 禁）

这条是**正确性约束**：为了让"没命中"这个回答能被证明，每个方向必须显式排除其它所有维度。
而"像人组织分类"的本质恰恰是**有取舍地忽略某些维度**。两者在结构上冲突：

- 想无假阴 ⇒ 必须全维度排除 ⇒ 谓词长、树全维度枚举、外部读不出意图
- 想有取舍 ⇒ 必须允许"某方向不表态其它维度" ⇒ 覆盖性失效 ⇒ 假阴回归

### ④ `merge` 是交集（L61-62），只会更窄

```python
req = frozenset.intersection(*[frozenset(d.payload[0]) for d in ds])
forb = frozenset.intersection(*[frozenset(d.payload[1]) for d in ds])
```

合并只会收紧，不会"放宽到某个意图的粒度"——所以也没有"上层按意图粗分"的路径。

### 结论

**S3-4 的红不是 bug，是"无假阴"这条正确性约束的数学后果。**
S5 的谓词漂移同理：新材料带来新的键值 ⇒ 二分时的兄弟集合与 `best` 都变 ⇒
`forb` 字面变，即使成员只增不减（63/63 存在超集）。

要让它"看起来像人的分类"，只有两条路，都会付代价：
1. **让意图参与选键**（`split` 接收 require，优先切意图相关的键）——树会变成"按意图组织"，
   但同一材料的"客观最优树"就没有唯一解了，S1（可复现）要重新定义。
2. **允许方向不表态某些维度**（放弃"成员 ⊆ 覆盖"）——谓词会短、会像人，
   但 `hit` 的"否"不再可证 ⇒ 假阴回归（§K8）。

这两条都属于内核设计变更，不在本阶段权限内（纪律 0.1：不许改被测代码）。

## 候选改动实验：倾向驱动的折叠（PREREG V4）——未获支持，但失败可诊断

**动机**：S3-4 的红是结构层"全维度枚举"的后果，动结构要付假阴代价。
问：不改结构、只在**呈现层**按倾向折叠（有取舍），能否让外部读者判"更像人"？

**实现**（内核零改动，只读包装器 `scripts/fold_probe.py`）：用真实 drill 产生倾向，
按倾向降序保留 K=8 个方向，其余折叠成一行「…（另有 N 个方向，低倾向，可展开）」。
两两强制选择：**D1** folded vs 不折叠；**D2**（阴性）folded vs 随机折叠。

| 组 | 结果 | 判据 |
|---|---|---|
| D1 主 | **folded 0/5** | PASS 要求 ≥4/5 ⇒ **FAIL** |
| D2 阴性 | **folded 0/5** | 归因：折叠内容无信号 |

### 失败可诊断到两条实现缺陷（读数级，不是猜测）

1. **保留集只有 3 个，不是 8 个**：101 个方向里只有 3 个有倾向记录（drill 了 3 支），
   其余 98 个被折叠 ⇒ 折叠版 1067 字 vs 不折叠 14802 字（**1:14**）。
2. **折叠把主干也折掉了**：保留的 3 个是 rank 很深的叶子，顶层父方向被折叠 ⇒
   读者看到的结构"**从中途层级开始**"。原话：「摘要2 开头直接从中途层级开始，
   后面大量『另有 N 个方向，低倾向，可展开』只是按数量罗列，**没有形成可读的整体结构**」。

模型还直接把折叠行本身读成机械痕迹：「大量使用『另有 N 个方向，低倾向，可展开』
这种**占位式递归**，像是在机械枚举低倾向分支」——折叠 UI 的措辞成了"机器味"的新来源。
D2 有 2 次直接答「看不出来」，理由同样是"两份折叠模式高度一致，都像机械枚举后的截断输出"。

### 结论（严格按判据）

**D1 FAIL ⇒ "呈现层折叠可改善像人程度"在本轮未获支持。**
但这是**实现缺陷**（保留集不足 + 主干被折）导致的否定，不能读作"折叠思路被证伪"。
按 PREREG V4 纪律（K 与折叠规则写死、不许调参重跑），本轮不重测。


### V5：修掉三条缺陷后重测——仍 0/5，但暴露了真正的信号

按 PREREG V5 只改三处（drill 8 支 / 祖先链一律保留 / 折叠行改结构语言），重测：

| 组 | 结果 | 字数 |
|---|---|---|
| D1v2（folded vs 不折叠） | **0/5** | 3073 vs 14802 |
| D2v2（folded vs 随机折叠） | **0/5** | 3073 vs 3918 |

10 次选择**全部**指向"另一份"（非折叠），且两次实验（V4 15 次、V5 10 次）的
原话给出同一个判据——**不是长度，是"并列 vs 单链"**：

- 判 folded 为机械：「摘要1 从『全部』开始**几乎只做排除法**，把大量小类堆在深层，
  像是机械地按条件逐个切分」「基本是**一条排除链一路向下**，分支极少」
- 判 full 为人：「先抓住最大的类别（article 3068 项），**保留多个并列分支**
  （article 下 2020 前后、review 下 2020 前后……）」「**分支上也更愿意合并/跳过**琐碎项」

对照 V3 的 G（groupby，26 行）被判"最像人"，理由同样是"type → evidence_status
**两层、并列清晰**"。三次实验合并起来，"像人"的操作性定义是：

> **扇出宽、层级浅、有并列** —— 而不是"信息少"或"有省略"。

**而 ldv 的形状恰好相反**：`split` 每层只做**二叉**（有它 / 没有它），
深度 16 层，长路径退化为单链；折叠把兄弟折掉，只会**让单链更单**。
⇒ **"按倾向折叠"这条路方向就错了**：它优化的是"减少信息量"，
而"像人"的判据是"增加并列宽度"。

### 结论（两轮合并）

- **D1（V4）、D1v2（V5）均 FAIL** ⇒ "呈现层折叠可改善像人程度"**未获支持，且方向相反**。
- 折叠越彻底，越像"单链穷举"。这不是实现缺陷，是**优化目标选错**。
- 若继续，"折叠"应换成**扇出重排**（同一父下的兄弟并列展示，而非逐行缩进链）——
  但那是**新的呈现假设**（不是折叠），需要独立预注册；且要小心它已接近"重新组织"，
  不再是"同一棵树的呈现"。


### V6：扇出重排——0/5，且被告知"路径重复=机械"

同一棵树、信息逐项相同（101 行 / 成员数多重集一致，机械校验通过），只改排版：

| 版 | 形态 | 字数 |
|---|---|---|
| chain（现状） | 逐行缩进链 | 14802 |
| fanout | 路径串 `A › B › C ｜ N` | 61876（路径前缀重复，4 倍） |

**D3 = 0/5**。理由不是长度，而是**重复**：

> 「摘要1（fanout）把每条路径都**压平成一行，路径前缀不断重复**，像机械地逐个列出所有节点」
> 「摘要2（chain）用缩进层级把分类关系表达成树状结构，读者能顺着层级理解『从大类到子类』的取舍」

## 三轮合并：呈现层三条路全部走不通

| 轮 | 改动 | 结果 | 模型给的理由 |
|---|---|---|---|
| V4 | 按倾向折叠（保留 3） | 0/5 | 「占位式递归」「从中途层级开始」 |
| V5 | 折叠 v2（保留 8 + 保主干 + 换措辞） | 0/5 | 「一条排除链一路向下，分支极少」 |
| V6 | 扇出路径串（信息等价） | 0/5 | 「路径前缀不断重复，机械逐项枚举」 |

三轮的**反向证据**合起来，给出"像人"的完整画像：

> **缩进树 × 层级浅 × 并列宽 × 谓词短 × 不重复**

ldv 现状只满足两项（缩进树 ✓、不重复 ✓），三项相反：

| 维度 | 人的样子 | ldv 实测 | 来源 |
|---|---|---|---|
| 层级 | 2–3 层 | **16 层** | `split` 每层只切一个键 |
| 并列 | 一父多子 | **二叉** | `split` 返回两个 payload |
| 谓词 | 短、正向 | `a ∧ b ∧ ¬(c ∨ d ∨ …)` | 单调继承 + 覆盖性要求 |

**⇒ 呈现层不是瓶颈。** 三个差异里没有一个能靠排版改掉（改掉就是"重新组织"，不再是同一棵树）。
要继续，只能动 `split`：①让意图参与选键 ②允许多叉 ③允许方向不表态某些维度（付假阴）。


### V7：活动 limit（覆盖率截断）——观感有效，但判据被骗了

**设计**（PREREG V7/V7.1/V7.2）：同一棵树，四份呈现件：
A 全量（101 方向 / 14802 字）、B 覆盖 95%（5 方向 / 247 字 / 深度 3 vs 16）、
C 覆盖 90%（与 B 相同）、B′ 随机 20 方向（2187 字）、B″ 随机 5 方向（788 字）。

| 组 | 对比 | 结果 | 判据 |
|---|---|---|---|
| **D4** | B vs A | **5/5** | ≥4/5 ✓ |
| **D5** | C vs A | **5/5** | ≥4/5 ✓ |
| D6 | B vs B′（随机 20，字数 9×） | 3/5 | ≈50% |
| **D7** | B vs B″（随机 5，字数 3×） | **3/5**（复验 **4/5**） | **未判定**（见下方复验注） |

### 双重结论

**① 对"观感"有效**：覆盖率截断后，读者 5/5 判"更像人"，且原话读的是**结构特征**：

> 「只保留了少数**高层、有解释力的切分**（type、era、source.kind），并在分支处用
> 『其余方向未展开』主动取舍，说明作者按自己的判断**控制了展开深度**」
> 「摘要2（全量）则几乎把每个剩余类别和否定条件都**机械地递归列到底，层级极深、条件串越来越长**」

这与 V4/V5 的判词（"一条排除链""占位式递归"）形成对照：**变浅变短确实改变了判断**。

**② "取舍内容"未能稳定判定**（复验后修正）：D7 首轮 3/5，复验 **4/5**——
脚本 sha256 相同、输入相同（seed 固定）、`chars`/`keep`/`cover` 全一致，
只有胜场数变了 ⇒ 落在 PREREG 阈值（≥4/5）两侧，两次会得出相反结论。

**统计上这条判据本来就分辨不了**：N=5 的强制二选一，真实胜率 50% 时出现 4/5 的概率
约 0.156、3/5 约 0.312。⇒ 本条**降级为"未判定"**，不得再引用为"取舍内容为空"。

可以保留的只有：模型认得出"**形状**"（浅、短、有省略痕迹）——那是 D4/D5 两轮都 5/5 的部分。

### 这与 S6-5 是同一个病

S6-5 里伪件（成员数打乱）也被读出"具体倾向"；V7 里随机截断也被读出"有取舍"。
两处合起来说明：**"看起来像人/有取舍"这个判据，可以被"省略"这个表层动作满足。**
因此它**不能**用来证明"结构承载视角"——这正是阶段二给"视角"打红的核心原因。

### 对"活动 limit"方案的判断（回答提问）

- **能改善观感**：是的，D4/D5 5/5，且效果稳定（两轮不同阈值、不同随机种子）。
- **能支撑"视角"**：**证据不足**。D6/D7 在 3/5–4/5 之间抖动（脚本与输入完全相同），无法判定"选对哪几支"是否有信号；这个 limit 至多提供"信息裁剪"，
  不是"取舍的表达"。用它去主张"结构有了视角"，会重蹈 S6-5 的覆辙。
- **可以正当使用的场景**：界面层的"默认展开深度"（用户可展开、账要平、阈值可审计）——
  这是**可用性**收益，不是**认识论**收益，两者不能混说。

> **复验注（2026-11-01 19:15）**：阶段二全部重跑后，D6/D7 由 3/5 变为 4/5，
> 其余读数（D4/D5 5/5、`chars`/`keep`/`cover`）逐字不变，脚本哈希相同。
> ⇒ 本条结论已按"未判定"处理，详见 `rerun_20261101/README.md` §3.2。

### 顺带的方法论结论（三轮合并）

| 改动 | 观感 | 取舍内容 |
|---|---|---|
| 折叠（V4/V5） | ✗ 0/5 | — |
| 扇出（V6） | ✗ 0/5 | — |
| 覆盖率截断（V7） | **✓ 5/5** | △ 3–4/5（未判定，脚本相同、复验翻转） |

唯一有效的是"变浅变短"，而它**恰好是判据的漏洞**。要检验真实取舍，
必须换一个**不会被"省略"欺骗**的问法（例如：给出两份同长度摘要，问"哪一份的取舍与
这份材料的下游问题更相关"），这需要在阶段三重新设计判据。


### V8：Tree Testing（首点正确率）——行为判据失效，但"可对齐率"给出机械证据

**设计**（PREREG V8）：A 树（从 `era=2020及以后` 进入，17 个顶层分支）与
B 树（从 `type=article` 进入，7 个分支），各配 10 个任务（A 类时间 5 个 / B 类类型 5 个）。
每任务一次调用，只给分支列表（谓词 + 成员数，编号），问先进入哪个。

#### 读数一（行为）：数字达标，但阴性对照红 ⇒ 不可采信

| 组 | 有效任务 | 首点正确率 | 阴性（谓词-成员数打乱） |
|---|---|---|---|
| A 树 × A 类 | 3/5 | **0.867** | **0.933** |
| B 树 × B 类 | 2/5 | **1.000** | **0.900** |
| B 树 × A 类 | 2/5 | 1.000 | 1.000 |
| **A 树 × B 类** | **0/5** | — | — |

**T4（真结构 − 打乱 ≥ 0.4）= −0.067，红。** 打乱"谓词↔成员数"后正确率几乎不变，
说明读者的选择**不是由谓词内容驱动**的（大概率是"选成员多的/选第一个"这类启发式）。
⇒ **T1/T2 的达标数字不能采信**；T3 因 A 树在 B 类任务上 0 个有效任务而**无法判定**。

本轮阴性对照的设计缺陷（必须记）：只打乱了"谓词↔成员数"的配对，**没有打乱分支顺序**，
而正确序号在真/伪两次调用中相同 ⇒ 位置启发式在两边都命中。要真正区分，需要
"只打乱顺序、保持配对"的对照，本轮未做。

#### 读数二（机械，不涉及读者）：**"可对齐率"显示 A 树确有时间偏向**

"有效任务"的判定本身是一个纯结构指标：该树顶层分支里，是否存在一个分支能覆盖
**≥50% 的目标项**（目标项由键集独立算出，与结构无关）。

| 树 | 对 A 类（时间）任务可对齐 | 对 B 类（类型）任务可对齐 |
|---|---|---|
| **A 树**（era 入口） | **3/5 = 60%** | **0/5 = 0%** |
| **B 树**（type 入口） | 2/5 = 40% | 2/5 = 40% |

**A 树对时间类任务的"能覆盖"比例 60%，对类型类任务 0%** —— 这是结构层的偏向证据，
而且**不依赖任何读者、不会被"省略"欺骗**。

它与 S3-4 并不矛盾：S3-4 看的是"顶层分支的谓词里含不含对方字段"（形式上几乎都含），
这里看的是"顶层分支的**划分边界**能否罩住某类目标"（功能上确实偏时间）。
**形式上是全维度枚举，功能上有偏向。**

#### 综合判读

- **行为层（能否被读者用起来）**：不成立（阴性对照红，数字不可信）。
- **结构层（是否偏向某个意图）**：**成立，但只在"可覆盖"意义上**——A 树对时间任务 60%、
  对类型任务 0%；B 树两类均 40%（无明显偏向）。
- 这与阶段二的总判定一致：**结构承载了一点偏向（机械可测），但这个偏向不足以被外部读者
  稳定读出或使用（行为不可测）**。所以"可审计的索引"这个定性不变，但要补一句：
  **它不是"完全中立"的索引，入口的选择确实改变了分支的覆盖结构。**


### V10：受限检索能否成为"视角素材"——**成立**（唯一通过严格阴性对照的正面结果）

**框架转向**（用户 2026-11-01）：ldv 内核 = **遗忘 + 注意力**；agent 是翻译层；
判据不该问"静态结构像不像人"（V1/V3 全红），而该问
**"能否从一次检索的形状里读出这个库的使用者重视什么"**。

**构造**：A = 含 `type=article` 的顶层方向、B = 含 `type=review` 的方向。
`drill(A)` 后把 A 的记录改老 300 天，`drill(B)` 保持"现在" ⇒
`t(A) = 0.0009`、`t(B) = 8.0`，`ordered_by = usage`，B 排第 1、A 排第 4。
给 agent 的只有**检索形状**（排序 + 谓词 + 成员数 + 倾向值），不给树、不给意图。

| 组 | 呈现 | 结果 |
|---|---|---|
| **真件** | 真实权重（B 高） | **5/5 指出 review** |
| **伪件（定向反证）** | 把唯一的大权重**强行赋给 A（article）** | **5/5 改口说 article** |
| W2（伪件仍说 review） | — | **0/5** |

原话（真件）：「更重视 2020 年以前、同行评审的综述（review）类方向」
原话（伪件）：「更重视 2020 年以前发表的期刊论文（`source.kind=journal` 的 article）」

**判读（PREREG V10.1 先写死）**：权重指向哪，回答就跟到哪 ⇒ **agent 读的是检索形状
（排序 + 权重），不是谓词内容、也不是先验偏好** ⇒ **受限检索可作为"视角素材"**。

#### 为什么这个结果和前面的全红不矛盾

| 之前测的 | 这次测的 |
|---|---|
| 静态结构（方向名 + 成员数） | **检索形状**（排序 + 倾向值 + 衰减后果） |
| 「这结构像人吗」 | 「这个库重视什么」 |
| V1 0/5、V3 0/5、V7 未判定 | **W1 5/5 + W3 5/5** |

**结构里没有意图，但检索形状里有。** 排序（注意力）+ 衰减（遗忘）这两个阶段一验过的机制，
恰好构成了"我总是先想到 X"这种视角的机制形态——而它**可被外部读出**。

#### 结论修正（重要）

原判："它是可审计的索引，不是视角。"
**修正为**：**结构不是视角，检索层是视角的载体。** 视角不在"材料怎么分类"里，
而在"**什么东西被排在前面、什么东西在淡出**"里——这正是注意力 + 遗忘的形状。

#### 限制（必须跟结论一起出现）

1. 单模型（deepseek-chat）· 5 实例 · 构造单一（article 老 / review 新的一个对照）。
2. "读对"用关键词判定（review / article），判定较粗；`cites_order` 5/5 但只记录外观。
3. 只测了"**读出来**"，没测"**用它做决策**"（下一步应是：给两个库的不同形状，
   让它决定先看哪个方向，看决策是否随形状改变）。
4. 伪件是"定向反证"（把最大权重给相反方向），只验证了"跟随最大权重"这一种形状；
   多权重、多方向叠加的情形未测。

### 若下一轮要重测，三个前置条件（本轮未做，写清留给下次）

1. **保留集必须真有 K 个**：drill 至少 8 个方向，或允许"无倾向 ⇒ 按默认顺序填满 K"。
2. **必须保留主干**：高 rank 的父方向一律保留，只折叠兄弟枝叶——否则层级断裂，
   读者第一句就会说"从中途开始"。
3. **折叠行不能用 UI 术语**：`另有 N 个方向（低倾向，可展开）` 被读成机器痕迹；
   需要换成结构自身的语言（如"其余分支未展开"），并让折叠行的措辞与真件一致。

## 能说的一句话

**同一材料上，ldv 的静态结构不携带可读意图（A 树顶层 17/17 含 type、B 树 7/7 含 era；配对 0/5），
抽象层也按设计对使用记录免疫（`P`/`E` 外生，§K9/`B14`）；但它的**检索层可以自己说出视角**：
只输出事实——「哪一支用过几次、最近多少天前」加一条公开的半衰期——外部 agent 即可 5/5 说出
「这个库最近重视 review」，且在「把最近使用换到 article」后 5/5 改口，**顺序打乱后仍 5/5**。**
⇒ **视角不需要压在 agent 上**：ldv 输出事实与机制，读者只做算术与措辞，不做猜测。
**结构是可审计的候选全集，视角由检索层的事实兑现；而且它进入行动**——把"最近使用"给一个只有 **2 项**的方向，agent 仍在 5/5 里放弃 2803 项的大方向去选它。

**但这一切的前提是翻译层受约束**：同一份结构摘要在无约束时被读出"倾向"（真件伪件各 5/5），加上"依据逐字、无证据必弃答"三条约束后，**逐字相同的两份摘要 5/5 被判无法区分**，结构摘要本身 5/5 弃答；而同一套约束下，事实清单仍 5/5 读出"重视 review"。

（限制：单模型 · 每组 5 实例 · 一个 article/review 对照 · 前 10 支 · 只验"读出"未验"据此决策"。）
