## 5. 一条方法论结论

**`temperature=0` 不等于可复现。** 本轮 62 项里 2 项变化，全部发生在
"真实胜率接近 50%"的判据上——远离阈值的判据（0/5、5/5）两轮完全一致。

⇒ 以后设计盲判，**每个实例组至少要能分辨出 20 个百分点以上的差异**（N≥20 量级），
或者把判据设成"远离 50% 的两侧"（如 0/5 vs 5/5），不要用 N=5 去分辨 3/5 与 4/5。
