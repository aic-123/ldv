## 2. 数值差异（如实记录）

判据判定一致，但有**一处数值不可精确复现**：

| 项 | 首次（11:48） | 本次（19:00） |
|---|---|---|
| X1 `tB` | `1.9996038099686555` | `2.0` |
| X1 `tA` | `0.0009765625` | `0.0009765625`（相同） |

**原因**：`probe_mechanisms.py` 把 `NOW = 2026-11-01 12:00` 写死，而 `drill` 写入的 `at`
是**真实墙钟**。首次运行时 drill 发生在 11:48（比 NOW 早 12 分钟）⇒ `w = 0.99981`；
本次在 19:00（比 NOW 晚 7 小时）⇒ `age_days` 被 clamp 到 0 ⇒ `w = 1.0`。

⇒ 这是**已知的构造瑕疵**（与 V11.2 撞的是同一件事），不是 `attention` 改动引起的：
本次改动只在 `query()` 返回值里加字段，**不触碰任何写入路径**。

判据不受影响：X1 断言的是 `tA < tB`、`posB < posA`、答案集逐字不变——三条都成立。
若需**精确**复现，应像 V11.2 那样把 drill 后的 `at` 显式钉到 `NOW`。
