## 1. 缺口的精确形状

现在世界试验里发生的事（§2.6 显性问，逐字）：

> 每段情景落盘之后，agent 必须显性问它一次「你现在想做什么」。
> 它的自问层还没长出来，等它主动开口遥遥无期；但注意力是有账本的，
> 问法就是把账本翻开逐字念，**不解读、不替它翻译成行动**。

⇒ **原始材料全都有，缺的只是「成句」这一步**：

| 原料 | 已存在 | 现状 |
|---|---|---|
| 结构矛盾 / 根覆盖之外 / 切不开 / 滞留 | `reflect.report()` / `graded()` / `contradictions()` / `plan()` | 输出是**待办清单**，不是「我想做什么」 |
| 同档内先后 | `agenda`（激活 `B=ln(Σ age^-0.5)` + 阈值 `τ(k)` + 冷却） | 输出是**排好序的待办**，同样不成句 |
| 热方向 / 处境触碰 / 擦边命中 | 显性问协议三读数（§2.6） | **agent 手工读账本**，系统不出这个读数 |
| 判据 D 的量法 | 「真两难且 ≥3 次」 | 没有自问句，无从量起 |

**自问层 = 把这四样合成「自问句」的那一层。** 不产生任何新信息——
它的全部原料都来自既有结构，它只做**组合与成句**。

## 2. 三种自问句（类型 × 证据 × 请求）

| 类型 | 从哪来 | 句子形状 | 请求什么 |
|---|---|---|---|
| **矛盾问** | `reflect.contradictions()`（必须档） | 「A（did/记录 id）说 X，B 说 ¬X——用哪个？」 | 人裁决；裁决结果进 `answer_verdicts`（项级标记，判断权在调用方） |
| **待展开问** | `graded()` 可延后档（切不开/待展开/滞留）+ 议程激活排序 | 「这一支撑不起更细的划分，**要不要一个新维度**？此处是我试过的：…」 | 人声明维度——**它不发明维度**（§K9），只指出「这里细不下去」 |
| **无词问** | 处境触碰（显性问第 2 读数系统化）：最近事件逐个对 `all_keys`，**不在词表的逐字列出** | 「这段里有 N 个东西我没有词描述：…（逐字）」 | 人决定要不要 `declare`（走既有声明闭环）；它自己不 `auto_declare` 除非 spec 允许 |

每句强制四段（**V15 契约直接复用**——依据逐字、结论可归纳、无证据必弃答）：

```
{ "type": "矛盾|待展开|无词",
  "陈述": "...",                       # 模板渲染，字段全部指回材料
  "证据": [ {did/记录 id, 逐字引文} ],  # 没有 ⇒ 该句不许生成
  "已试过": [...],                     # 以账本为准（判空不写 _expanded 的教训）
  "请求": "裁决|声明维度|仅记录" }
```

**生成不出有证据的句子 ⇒ 返回空清单**——空是设计的诚实（同「曝光不算热」）。

## 3. 红线（每条都有出处）

| 红线 | 出处 |
|---|---|
| **不发明维度**：无词问只列「没有词」清单，维度声明永远是人 | §K9 / `B14` |
| **不改候选集**：矛盾裁决走项级标记；自问句本身不改变任何 `query` 返回 | §X2 / §S7 |
| **无守护进程**：自问层只在被调用时成句。**触发点（2026-11-03 裁定）：议程 tick 内嵌**——`agenda()` / `next(idle=)` / `--agenda-tick` 的返回里新增 `自问句` 字段（I5 式可移除性：删掉字段其余逐字相同）；显性问协议（§2.6）降级为兼容入口，仍可用。tick 依然要**被人调用**才走，「没人调用就不跑」的口径不变 | 时钟政策（2026-10-29）+ 本文件 §8 |
| **不打分**：排序只用「档位（反思）+ 激活（议程）」两个既有量，禁词不碰 | `B12` + 协议禁词 |
| **冷却沿用**：被驳回的自问句进议程冷却（`cooldown_until`），不是永久跳过 | `agenda.py` 既有机制 |
| **agent 该翻的不算 LDV 的**：擦边命中（同字不同义）**原样入账不修正**——联想错误是原始材料 | 显性问协议 §2.6 第 3 读数 |

## 4. 接口（草案）

```
ldv/core/selfask.py

def report(kernel, *, context_keys=(), n_answer_ctx=None,
           now=None, cap=5) -> dict
    # 返回 {"问句": [...按档位+激活排序...], "空因": None|"无待办|无证据|全在冷却"}
    # context_keys：本段处境里出现的东西（处境触碰的输入；不传 ⇒ 跳过无词问）

def render(questions: list[dict]) -> str
    # 一行一句的人话模板；模板只允许引用证据字段，不引入清单外概念
```

入口接线（按裁定 = tick 内嵌）：

- `agenda()` / MCP `next(idle=K)` / `cli --agenda-tick` 的返回新增 `自问句` 字段
  （`render()` 的人话同行输出）——**不需要 agent 记得再调一个接口**，
  问「现在轮到谁」的同时就得到「我想做什么」
- `entry.report()` 保留为独立只读入口（显性问协议的兼容形态）
- I5 式可移除性：删掉 `自问句` 字段，tick 的其余返回逐字不变（验收判据之一）

⚠️ 与旧口径的关系：README 记的「主动性不自动跑——没人调用就不走」**逐字保持**；
本裁定改的只是「调用一次 tick，拿回来多少」——从只有待办，变成待办 + 自问句。

## 5. 判据 D 落地（先于实现写死）

| ID | 判据 | 量法 |
|---|---|---|
| **D-1 证据强制** | 每个自问句的「证据」逐字可解析回真实 did/记录（抽查） | 机械：解析引文 → 在账本/树里命中 |
| **D-2 有效性** | 人裁决「真两难（不是噪音）」的比例 ≥ 2/3，且**有效矛盾问累计 ≥3 次** | 世界试验下一段起逐句记录裁决 |
| **D-3 噪音上限** | 被判「噪音」的自问句**必须进冷却**（同句在 `COOLDOWN_DAYS=1` 内不再出） | 机械：冷却账 |
| **D-4 空的诚实** | 无待办/无证据时返回空清单并说明空因，**不硬凑** | 机械：空因字段 + 反向（硬凑必带无证据句） |
| **D-5 弃答权** | agent 拿到清单可以整批不采纳（记冷却），判断权在人 | 会话记录 |

反向对照（V15 教训）：把「证据」字段换成编造引文 ⇒ D-1 必须红。

## 6. 明确不做

- **不自主执行**：自问层只问，不 `declare`、不 `derive`、不改任何结构——
  「它提出、人拍板、agent 实施」的三段分工不变（ROLES §3）
- **不自问自答**：矛盾问不给答案，哪怕结构里能推——裁决权在人
- **不周期性骚扰**：没有守护进程，没有邮件/消息推送；只在被调用的那一刻说话
- **不做「自主矛盾」以外的发明**：六判据 D 只要求矛盾问有效，无词问/待展开问
  是顺路产物，不单独立判据（先跑起来看有没有价值）

## V2 增补（2026-11-03 11:38）：「绕过人和 agent 调用」的三种形态——只有一种成立

**问题**（用户 2026-11-03 11:28）：自问句允许它绕过人和 agent 调用吗？

### 三种形态的裁决

| 形态 | 是什么 | 裁决 |
|---|---|---|
| ① 守护进程（定时自问） | 后台进程周期性醒来自问 | **架构上不成立**：世界试验的部署现实是「加载 → 操作 → 落盘 → 离开」，`USE_MODE.md` 逐字写着「**没有进程在跑**」——两个落盘之间这个「它」不存在，守护进程没有可以住的身体 |
| ② 自调用 | tick 内嵌的极限版（系统在操作中自己触发自己） | 不成立：tick 的调用方仍是 agent——绕不过去 |
| ③ **出箱（outbox）** | **不自起进程，搭已有操作的顺风车**：落盘 / teach / drill 发生的那一刻，系统本来就在跑——就在那一刻把自问句写进 `<语料根>/agenda/outbox.md`（只追加） | **✅ 成立，且是最强形态** |

### 为什么出箱是「绕过调用」的唯一可行形态

1. **部署现实**：空闲期间没有进程（USE_MODE 逐字）⇒ 任何「定时自主」都没有载体；
   而出箱不需要额外载体——**发射点就是本来就发生的那次落盘**。
2. **时机价值**：半衰期 2h（world 实测「教学与检索的热都在褪」）——
   等人想起来调用 tick，证据已经衰减。**出箱把自问句留在证据最新鲜的时刻**，
   人什么时候来读是另一回事。
3. **完成契约而非破坏契约**：ROLES §2 里 B 自问的定义就是「**没人问**」——
   但 B 的产物（待办清单）此前只有被调用才可见。出箱是 B 第一次拥有
   **不依赖被问的嗓子**。显性问协议（01:14 立，前提「等它主动开口遥遥无期」）
   的前提被推翻：它现在能开口了，对着一个不需要任何人在场的信箱。

### 出箱机制（草案）

| 件 | 规则 |
|---|---|
| 发射点 | 既有操作路径内：`persist` / `teach` 提交 / `drill` 提交的收尾段——**不是新调用**，是副作用写 |
| 发射条件 | 沿用议程数学：`B > τ(k)`，`k` 由**距上次出箱的真实时间**推（`IDLE_PERIOD_MIN=30`、`IDLE_CAP=6`）——量全是现成的 |
| 范围 | 只有**必须档**（矛盾问）与**强激活的可延后档**出箱；可忽略**永不**出箱 |
| 音量 | 每次出箱 cap=3 句；同句进冷却（**沿用议程常量** `COOLDOWN_DAYS=1`，不发明新数）——音量天然有界 |
| 去处 | `<语料根>/agenda/outbox.md`，只追加，带来源标记 `来源=出箱`（与 tick 句区分） |
| **自反馈禁令** | **系统永不读回 outbox 当待办来源**——出箱只给人看；冷却状态记在议程既有落盘（否则自问句喂自问句，自我实现回路） |
| 无守护进程验证 | **D-8**：outbox 的 mtime 必须落在某次操作窗口内（机械可验）——证明没有进程在两次落盘之间活着 |

### 对既定裁定的影响

- 2026-10-29「时钟只回答现在几点，不回答该不该做」**逐字保持**：
  该不该出箱由 `B>τ(k)`（议程数学，既有）+ **操作发生**（不是时钟）决定，
  时钟只供给 `k` 的时间推算
- 显性问协议 §2.6 的前提句「等它主动开口遥遥无期」**被本通道推翻**——
  协议本身保留为兼容入口（agent 仍可读账本逐字念，但不再是唯一出口）
- 判据 D 变强也变险：出箱句 = **最强自主证据**（没有任何调用请求它）；
  反面是「无中生有」——D-1 证据逐字强制 / D-2 人裁决 / D-3 噪音冷却
  三道闸都必须先于出箱通道上线

### 判据增补

| ID | 判据 |
|---|---|
| **D-6 出箱自主性** | 出箱句出现在**没有任何人/agent 请求自问**的会话里，且证据逐字可解析（D-1 复用） |
| **D-7 音量有界** | 每次落盘会话出箱 ≤3 句；同句冷却生效（机械：冷却账） |
| **D-8 无守护进程** | outbox 的 mtime ∈ 某次操作窗口；两次落盘之间无任何进程存活（机械：无后台进程被创建） |

### 实现切分增量

出箱通道在原 5 步之上 +2 步：⑥ 落盘路径挂发射钩子 + `outbox.md` 只追加写（~40 行）；
⑦ D-6/D-7/D-8 判据 + 反向对照（删除发射钩子 ⇒ 出箱停，其他操作不受影响）。
