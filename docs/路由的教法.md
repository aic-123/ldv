# 路由的教法

**版本** v0.2.27 ｜ 2026-11-10 ｜ 对应语料节点 `conc/537 路由的教法`

> 这份文档只回答一件事：**一条路由该怎么教给它**。规矩在语料，算子（怎么换写法、怎么发一次）在代码；
> 代码里不许出现业务判断——出现了就是教错了位置。

---

## 一、七段骨架（缺一段不算教完）

每条标了 `形态: 路由` 的节点，正文必须按这个顺序写七段，段名用两个星号包住：

| 段 | 写什么 | 反例 |
|---|---|---|
| `**触发**` | 什么情形走它。判据要**看得见**：status、`reason`、字段名 | 「感觉不对的时候」 |
| `**动作**` | 具体做什么，取最小动作 | 「妥善处理」 |
| `**停手线**` | 什么时候**不许**做；猜错的后果写在这儿 | 只写「要小心」 |
| `**次数**` | 做几次、边界在哪 | 不写次数 ⇒ 会无限试 |
| `**留痕**` | 交出什么让人能复算 | 「记一下」 |
| `**依据**` | 点名哪本规程、哪个节点 | 「按惯例」 |
| `**可移除**` | 删掉这个节点，行为退回什么样（I5） | 写不出 ⇒ 它偷偷改了别处 |

判据 `D-Route2` 会扫真语料：**凡是标了 `形态: 路由` 的节点，七段少一段就红**。

## 二、分工与授权

- **规矩在语料**：什么时候能改、改到哪、改几次、谁给值——全在节点正文里。
- **算子在代码**：怎么把 `11/08/2026` 换写成 `2026-08-11`、怎么发一次 HTTP。
- **授权方式**：每条路由一个 `_xxx_rule()`，去语料按 `name=` 找节点；找不到 ⇒ 走旧路，
  **与上一版逐字相同**。这就是 I5（可移除性）的可执行形态。

| 路由 | 授权方法 | 找不到时的行为 |
|---|---|---|
| 回执凭据层 | `_credential_rule()` → `name=回执凭据层` | 只扫顶层白名单 |
| 改格式重发 | `_port_retry_rule()["改格式"]` → `name=改格式重发` | 4xx 一次就报，不改不重发 |
| 对方故障有界重试 | `_port_retry_rule()["故障重试"]` → `name=对方故障有界重试` | 5xx 一次就报，不重发 |
| 报缺 | `_missing_rule()` → `name=报缺单` + `name=客观事实与可推事实` | 弃答只留一句「报人」，无 `报缺` 字段 |

## 三、判据规矩

每条路由至少三条：

1. **正向**：教过 ⇒ 那样做（带上留痕字段）。
2. **反向**：没教过 ⇒ 旧样（逐字对拍，不是"差不多"）。
3. **停手线**：越界情形 ⇒ 不做（比如日序定不了就不改日期）。

⚠️ 判据里用假 App 时，**用到的节点必须给全**：v0.2.26 踩过一次——假 nodes 少了
`conc/532`，201 回执读不出嵌套凭据，两条重发判据被误判成红。

## 四、命名

`name` 四到六字，动宾或名词短语，人一句话能叫出来（《改格式重发》《对方故障有界重试》《报缺单》）。
**名字是代码找它的唯一钥匙**——改名字等于换路由，旧名字会静默失效。

## 五、不回溯

v0.2.27 之前教的路由（`conc/532`《回执凭据层》、`conc/533`《改格式重发》、
`conc/534`《对方故障有界重试》）保留原样，**不补段、不改写**。
历史归历史，规矩从这一版起；回溯改旧节点会让既有判据的逐字对拍全部失效。

## 六、教一条新路由的动作

1. 写节点文件 `nodes/conc__NNN.md`，front matter 带 `形态: 路由`，正文七段齐全。
2. `App.taught([id])` 记教学链并自动开词（**跳过它只写文件，节点查得到但没有教学链**）。
3. 代码里加 `_xxx_rule()`，只在"节点在"时生效。
4. 加判据：正向 / 反向 / 停手线。
5. 同步运行副本（`repo/` ↔ `_snapshots/ldv-work/` 逐字一致），跑 `run_tests` 与 `run_checks`。

## 七、现在有哪些路由（截至 v0.2.27）

| 节点 | 路由 | 一句话 |
|---|---|---|
| `conc/532` 回执凭据层 | 读回执 | 顶层没有凭据就往里看一层，路径一起记；数组里的 id 不算 |
| `conc/533` 改格式重发 | 4xx | 只改**写法**，改一次发一次；日序定不了就不猜 |
| `conc/534` 对方故障有界重试 | 5xx | 报文一字不改原样重发，最多 2 次 |
| `conc/535` 客观事实与可推事实 | 分界 | 有依据的是可推，指不出依据的就是客观事实——**报缺，不猜** |
| `conc/536` 报缺单 | 缺事实 | 出单：缺什么 / 哪一类 / 对方原话 / 要谁给 / 给了怎么用 |
