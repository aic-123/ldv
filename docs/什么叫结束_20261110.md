# 什么叫结束：跑完了不等于做成了（v0.2.31，2026-11-10）

**用户一句话**：「教它什么叫结束不就行了」。

上一轮我提了两条补法（教取字段、给差距/建议加入场判据），都没要。要的是更前面那一层：
**它不知道什么叫结束**——所以 A 走满 5 段、每段都 `ok`，报的是「成功」；
任务书要的是**一条补法**，它手里是一份把整段 JSON 当需求量出来的噪声单。

---

## 一、教的是什么

**`conc/546《什么叫结束》`**（门类 自我 / 领域 方法论 / 形态 路由，七段齐全，已 `taught`：教学链 10 条 + 自动开词）：

- **触发**：一段路走完要报「做成了没有」的时候——段数走到头、没下一段可走、每一步都返回 ok。
  这里最容易把**跑完了**说成**做成了**。
- **结束的信号**是任务书里「要什么」那一句**被兑现**，不是这一段的返回值。
- **三种假结束**：
  - **中间件冒充成品**——手里是单据 / 回执 / 清单 / 凭据 / 候选，那是给下一步用的；
  - **噪声冒充结果**——结果里一大片候选、碎片、陌生片段，说明进去的东西形态就不对；
  - **段数用完冒充走完**——走到第 5 段不叫完成，叫**用完了**。
- **停手线**：没到手只有一条出口——停 + 报缺；不许为凑完成再加段；不许把「每段都 ok」当成绩报上去；
  结束只判一次，判完不改口。
- **留痕**：`任务书要什么 / 手里现在是什么 / 凭什么这么判`，三样缺一不许下判。

## 二、怎么接的线

`_finish_rule()` 找这个节点（没教过 ⇒ 组合与 v0.2.30 **逐字相同**：不要求 `要`、不判结束）。

教过之后：

1. **`{"组合": …}` 必须给 `要`**——任务书要什么。不给就**一段都不跑**（在形状校验之后就拦，
   不会让端口先发出去）：
   > 《什么叫结束》：任务书要先说「要」什么——不知道要什么，我没法说结束，也不替你编一个。
2. **收尾摊开 `结束` 三样**，只判两件**确定**的事，语义不替人拍：

| 情形 | `到了没` | 凭什么 |
|---|---|---|
| 末段弃答 | **没到** | 第 N 段弃答，后面的段没走 |
| 走满 5 段 | **用完了** | 段数用完是过程，不是结果 |
| 其余 | **判不了** | 三样摊在这儿，对不上就按《什么叫结束》报缺 |

3. `ok` 仍表示「这一串跑完了」，**与「到了没」分开写**——这是本版最关键的一处：
   以前 `ok=True` 就等于「成功」，现在它只说「跑完了」，做成没有看 `结束`。

| B 真开票（201 / INV-0001）→ 推演 | 2（停 2） | ok=False | **没到**：第 2 段弃答 |

| D 单据挑一句 → 差距 | 2 | 「走完」 | **判不了** |

A 的完整读数（这就是用户要的那句人话）：

```
▸ 结束：到了没＝用完了
    任务书要：一条补法，能指给人照着补
    手里是：{"ok": true, "路由": "建议", "需求": "{\"ok\": true, \"路由\": \"差距\"…", "新词候选": [" \"", "宇宙", …]}
    凭什么：走满 5 段是段数用完，不是完成；要的东西兑没兑现，得拿任务书那一句对
```

它不再说「成功」，说的是**用完了，而且手里那东西不是任务书要的**。

## 五、这一版没做的（两条边界，说在前面）

1. **「用完了」之后的报缺，仍要人接。** 节点写着「没到手只有一条出口：停 + 报缺」，
   但代码只知道「没到」，不知道「缺什么」（那要读任务书语义）。所以现在它说的是
   「用完了，要的东西没到手」，**报缺单得由人/agent 按《报缺单》conc/536 补**。
2. **「判不了」不是懒。** 末段交出的东西兑没兑现任务书那一句，是语义判断；
   我不替它拍，也不假装拍得准。三样摊开，人一眼能判，它自己不冒充判过。

另外上一轮那两条缺口**仍然在**（`«上一步»` 只能整段搬、取不出 `INV-0001`；差距/建议自己没有
入场判据）——只是现在多了「结束」这一层，**垃圾进垃圾出的那一段会被标成「用完了 / 判不了」，
不会再被报成成功**。
