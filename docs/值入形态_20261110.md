# 值入形态：句子我出，值你给（v0.2.33）

用户 2026-11-10：「翻译层肯定不能让它来填，但是它可以告诉 ldv 这就是要填的值呢」。

上一轮测出的事：让翻译层自己造句去贴边的前提，**差两个字就断**——

```
T5a  …状态为 settled（2026-11-10T17:40:02）        → 断
T5b  …状态为 settled（2026-11-10T17:40:02 结算）   → 通
                                    ↑ 只多这两个字
```

措辞是语料里的，翻译层看不到边，只能猜。所以本版把分工倒过来：**LDV 摊出形态、自己填值；
外面只交值。**

## 一、分工

| | 谁干 | 交付物 |
|---|---|---|
| 措辞（句子怎么写） | **LDV**，取自已教的边 | 报缺时摊出 `入边形态` |
| 值（编号 / 日期 / 状态） | **外面**（翻译层、人、研究员） | `{"原": 旧值, "成": 新值}` |
| 填进去 | **LDV**，在自己的边上换 | `填入` 留痕 |

翻译层不再写句子，所以也不会再因为少了两个字而断。

## 二、教的那条：`conc/551《值入形态》`

形态: 路由，七段齐全，已 `taught`（8 条教学链 + 自动开词 `name=值入形态`）。

- **触发**：外面给来一个值，说「这就是要填的」——只给值、不给句子。
- **动作**：先在自己边里找出含这个值的那一位 → 只换值、**措辞一个字不动** →
  前提和结论一起换（只换一半，下一跳就断在这半句）→ 换完再走，走不通就说「值填了，仍然接不上」。
- **停手线**：只填外面给的值（日期、金额、状态要一个给一个，不许自己补）；库里没这个位就不填；
  **不换规则与依据**（那是这条边为什么成立，不是数据）；**不生成新边**（代入不是造边）。
- **留痕**：逐条记原值/新值/命中哪几条边的哪一侧，并标明「这一条起点由外部值代入生成，不是语料原文」。

## 三、接的线

- `_fill_rule()` 找节点；**没教过 ⇒ `填` 不生效**，与 v0.2.32 逐字相同（I5）。
- `推演` 新增 `填`：`[{"原": 旧值, "成": 新值}]`，也接受 `{"原":…,"成":…}` 单条。
  只给值 `["RF-0009"]` 会被拒：「只给值，不给句子；句子我这边有」。
- `_apply_fill()`：在**边的前提与结论**上逐字替换，记命中；不碰规则与依据。
- 报缺单新增三样（教过才加）：`入边形态`（这条缺口的入边长什么样，取自已教的边）、
  `值位`（编号 / 日期 / 百分数 / 量纲值 / 小数，只列认得出的）、`怎么填`（给出 spec 写法）。
- 返回新增 `填入` 与 `填值来源`（明写：**值来自外部，不是语料原文**）。

## 六、边界（必须说清）

1. **值本身没人验**。LDV 会把你给的值填进它的边，然后照那条边走到底——
   你给 `RF-0009`，它就能推出「这笔退款可以结案」，哪怕台账里没有这笔。
   它能做的是**标明**「值来自外部」，不能判断值真假。所以 `填值来源` 不是装饰，
   是这条链上唯一说明「这一步不是推出来的」的地方。
2. **值位只认认得出的形态**：编号、日期、百分数、量纲值、小数。自然语言里别的值
   （「上升」「已通过」这类）认不出来，不列——宁可少列，不替人把一句话拆错。
3. **规则与依据不跟着换**：换的只有事实那一侧。如果值变了、规矩也该变，那不是代入，
   是另一条边，得教。
4. **填值是逐条替换，不是模板**：同一个旧值出现在几处就换几处（本例 3 处）；
   如果一处该换、另一处不该换，说明这条边把两件事写在了同一个值上——那是边的写法问题，
   代入救不了。
