# LLM 桥接接口（只留接口，不留密钥）

外层 LLM（DeepSeek/GLM 均可）通过**五个工具**接入 LDV。分工铁律见
《外接应用开发规范》（语料侧规程，此处是接口侧的形状）：

- **LLM 管**：读自然语言、定意图、把话翻译成方言、组织成话；
- **LDV 管**：答不答、答什么、凭什么——数值只认它的「算得」，知识只引它的正文。

## 工具契约（五件）

| 工具 | 入参 | 返回 | 备注 |
|---|---|---|---|
| `ldv_search` | `require: string[]`（谓词列表） | 命中节点正文与骨架字段 | 谓词形如 `name=X`、`门类=文字` |
| `ldv_converse` | `说: string` | `路由 / 答 / 听到` | 方言示例：「声速乘三」——操作数必须来自 ldv_quantities 的名单 |
| `ldv_expr` | `树: {op,a,b}`（叶子 `{"name":"六"}`） | `算式 / 算得` | 嵌套表达式树，中间数不落地，一次算到底 |
| `ldv_quantities` | — | 全部带数值的量名 | 算式方言的合法操作数；数值本身不是词汇 |
| `ldv_dims` | — | 全部可检索维度键 | 先看仓库有什么再查 |

## 分工纪律（system prompt 必须写明的三条）

1. **不造数**——所有数值结果必须来自 `ldv_converse`/`ldv_expr` 的「算得」；
2. **不替判**——允不允许、缺不缺，由 LDV 说；agent 只执行与转述；
3. **不藏翻译**——把话翻成方言要交出整句 spec，不许心里翻译直接给答案。

## 密钥与路径

- 密钥：环境变量 `LDV_DEEPSEEK_KEY`（或所用模型对应变量），**仓库不存密钥**；
- 语料根：环境变量 `LDV_ROOT` / `LDV_NODES`；
- 参考实现：`exp/ldv_agent.py`（消毒版：密钥与绝对路径全部改为环境变量）。
