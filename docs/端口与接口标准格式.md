# 端口与接口标准格式

**对端**：LDV v0.2.17（判据 1041 全绿）
**用途**：给外层 agent / 应用开发者照着接。**每一个格式都在本机实测过**；未实测的会标「未验」。
**原则**：一问一 spec；单通道不混用；返回值一律带证据或不带答案。

---

## 一、总则（三条硬规矩）

1. **一次只发一个通道**。`{"derive": …, "主题": …}` 会被拒：组合通道互斥。
2. **只填这一通道认的键**。填错键不会被忽略，会**当场拒并列出它认哪些键**。
3. **`ok: true` 才有答案**。`ok: false` 时读 `弃答`（或 `error`）——那是它的原话，**不要改写**。

---

## 二、进程内通道（Python `App.query(spec)`）

### 2.1 检索（基础通道，非组合）

```python
{"require": ["门类=文字", "文字用法=语法"], "forbid": ["门类=词汇"]}
```

- 返回：`ok` `node` `nodes` `n_branches` `answer_titles` `out_of_structure` …
- **命中 0 条 ≠ 材料里没有**：它会回 `out_of_structure: true` 与 `suggest` 相近名字。
- 谓词不支持时，`need_predicate` 会说明「可声明性」与理由（`可声明: false` 表示声明只会得到空维度）。

### 2.2 组合通道一览（互斥，spec 只放一个键）

| 通道 | 格式 | 必填 | 弃答原文（实测） |
|---|---|---|---|
| **derive 推算** | `{"derive": {"运算":"/","左":"name=七十八","右":"name=十","字段":"数值"}}` | 运算 + 左 + 右 + 字段 | `不认识的运算符` / `除零没有定义` |
| **solve 方程** | `{"solve": {"运算":"+","已知":"name=三","side":"右","得":5,"字段":"数值"}}` | 运算 已知 side 得 字段 | `不唯一` / `无解` |
| **链式** | `左` 可以是**内层算式**：`{"运算":"*","左":"name=声速","右":"name=四","字段":"数值"}` | 同上 | 任一环弃答则整链弃答 |
| **moral 道德反查** | `{"moral": {"事": "name=捡到"}}` | 事 | `没对上` / `多命中` |
| **分析** | `{"分析": "name=捡到"}` | 名字 | `这件事还没有对上道德 —— 要不要教` |
| **成文** | `{"成文": "name=X"}` | 名字 | 同上（依赖分析） |
| **变形** | `{"变形": {"句": …, "式": "被字句"}}` | 句 + 式 | `没教过的句式` |
| **反义** | `{"反义": "大"}` | 词 | `没教过的对子` |
| **主题成文** | `{"主题": {"题": "院墙根的蒲公英", "词": ["蒲公英","砖缝"]}}` | 题 + 词 | `料不够（只找到 N 条）——先教相关的概念` |
| **造句** | `{"造句": {"词": "蒲公英", "式": "比喻句"}}` | 词（式默认比喻句） | `还没有词卡（不知道它的词类）` |
| **查字典** | `{"查字典": {"字": "挑"}}` / `{"部首":"火"}` / `{"音":"huǎng"}` / `{"歇后语":"芝麻开花"}` | 四选一 | `只认 ['字','部首','音','歇后语']` |
| **联想** | `{"联想": "光"}` | 词 | — |
| **对话** | `{"对话": "你好"}`（或 `{"说": "..."}`） | 说 | `这句话里的词我都不认识` |

### 2.3 v0.2 的新通道（本文重点，全是「清单」，不是「结论」）

| 通道 | 格式 | 必填 / 弃答原文 | 产物 |
|---|---|---|---|
| **差距** | `{"差距": {"需求": "<整条原话>"}}` | `差距要「需求」——把原话给过来，不要先翻译成判据` | 三档：契约内 / 契约外（有弱相关）/ 只有词义 |
| **建议** | `{"建议": {"需求": "<整条原话>"}}` | `建议要「需求」——整条原话给过来，不切句` | 四份清单：覆盖 / 新词候选 / 要动的条文 / 缺的口径 |
| **装配** | `{"装配": {"名称": "X"}}` | `装配要「名称」——装哪件事的目标` | 判据逐条 → 有 / 弱 / 缺（**不排顺序**） |
| **过程** | `{"过程": {"名称": "X"}}` | `过程要「名称」` | 步骤表 + 完整度（缺就如实缺） |
| **端口** | `{"端口": {"做什么": …, "为什么": …, "请谁处理": …}}` | 三字段，缺一即拒 | 主动调端口并**消费返回** |
| **mongo** | `{"mongo": {"op": "find", "集合": "loans", "文档": [...]}}` | `op` 白名单：`hello/ping/count/find/aggregate/insert/update/结存` | 直连 27017 的结果 |
| **借阅** | `{"借阅": {"操作": "借书", …}}` | 只认 `借书/还书/查库存` | 判定 `允不允许 / 为什么 / 待写` |
| **接口定义** | `{"接口定义": {…}}` | —（见《API 定义规范》节点） | 按规范产出 **OpenAPI 3.0** |
| **查询** | `{"查询": {"问": "<问句>", "账": true}}` | `查询要「问」——没有问句我不猜` | 问句 → 通道；`账: true` 带账本 |
| **外查** | `{"外查": {"问": "<问句>", "预算": N, "领域": …, "学名": …}}` | `外查要「问」——带着问句出去，不许"随便看看有什么"` | 外部检索（有出处才学） |
| **评估** | `{"评估": {…}}` | 未验（参数以《评估规程》节点为准） | — |

> 「装配 / 过程 / 差距 / 建议」四条的共性：**只出清单，不替你决定**。顺序、取舍、执行都在调用方。

### 2.4 返回体通用结构

```json
{
  "ok": true,
  "算式": "340.0 * 3.0 = 1020",
  "算得": 1020,
  "依据": [{"原文": "nat/046（声速）的 数值=340", "可复算": "查询 `name=声速` ⇒ 命中 nat/046"}],
  "语料中算得值的节点": [],
  "请求": "算出了 1020，但语料里没有数值=1020 的节点——这个数还没有名字，要不要教",
  "长说明": "…本层只做计算与引用…",
  "上次作答": {"时间": "2026-11-05T18:32:35", "可复算": "重跑同题应得同一结果"}
}
```

| 字段 | 用途 |
|---|---|
| `依据[]` | **必读**。`原文` 是坐标，`可复算` 是复核指令 |
| `请求` | 它主动开口要的东西（要不要教 → 该由**人**答） |
| `缺料[]` / `弃答` | 缺什么、为什么不答；`弃答` 原话转达 |
| `上次作答` | 同题重问的自动对账 |

## 三、HTTP 端口（`serve.py`，多租户服务）

**认证**：`serve_auth.py`（token）。**配额**：`serve_sched.py`（每分钟次数，超限 429）。

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/healthz` | — | 进程活着 |
| GET | `/readyz` | — | 语料坏 ⇒ **503**，并指明哪个租户 |
| GET | `/metrics`、`/metrics.json` | — | 读数 |
| GET | `/tenants` | — | 租户清单 |
| POST | `/tenants/{name}` | body | 建租户 |
| DELETE | `/tenants/{name}` | — | 删租户 |
| GET | `/tasks/{id}` | — | 异步任务状态 |
| GET | `/{tenant}/ask` | `require` / `forbid` / `plugin` / `limit` / `refresh` | **只接受这五个**，多传 → 400 |
| GET | `/{tenant}/agenda` | — | 议程（到点项） |
| GET | `/{tenant}/run` | 同 ask | 同步跑 |
| POST | `/{tenant}/run` | 同 ask | 提交异步任务 → 202 + task id |
| POST | `/{tenant}/drill` | — | 下钻（合法反馈） |

**错误约定**：`400` 参数不认（会列出认哪些）、`401/403` 认证/越权、`404` 端点或租户不存在、`429` 配额、`500` 语料坏（带文件名）。

## 四、MongoDB 端口（27017，线协议直连）

`ldv/core/mongowire.py` 只用标准库实现，**不借驱动**。协议本身教在 `conc/396（MongoDB 端口协议）`。

### 报文格式

```
报文头 16 字节：长度 int32 | 请求号 int32 | 响应号 int32 | 操作码 int32
操作码 OP_MSG = 2013
OP_MSG 体    ：flagBits int32 | 段…
段           ：kind 字节 + 内容
               kind 0 → 一个 BSON 文档（命令本体）
               kind 1 → 文档序列（identifier 指明塞给哪个字段，如 cursor.firstBatch）
```

### 命令即文档

```json
{"find": "loans", "filter": {"归还": null}, "$db": "lamp_oil"}
{"insert": "loans", "documents": [{...}], "$db": "lamp_oil"}
{"count": "loans", "query": {}, "$db": "lamp_oil"}
{"ping": 1, "$db": "admin"}
```

- **每个请求自带 `$db`**，协议里没有"先 use 库"这一步。
- 回执 `ok=1` 成功、`ok=0` 失败（`errmsg` 原因、`code` 错号；13/18 = 没权限）。
- **空结果不是连不上**：`ok=1` + `firstBatch: []` ⇒ 账面就是零。

### 支持的 op（白名单，实测原文）

`hello / ping / count / find / aggregate / insert / update / 结存`
其余一律：`不认识的 op「X」——《MongoDB 端口协议》只认 …`

## 五、端口调用规程（`{"端口": …}`）

**三字段必填**，缺一个就拒，缺的它不替你编：

| 字段 | 意思 | 例 |
|---|---|---|
| `做什么` | 调这个端口要干什么 | `把本期对账结果发出去` |
| `为什么` | 依据哪条规矩 | `《对账规程》④ 要求出箱留痕` |
| `请谁处理` | 谁接这个活 | `账务服务 /api/recon` |

三条纪律（写在 `conc/393`）：**三字段必填 / 返回必须消费 / 失败不重试**。

---

## 六、调用纪律（踩过的坑）

1. **不许自己心算**：任何数值都得有一次 `算得`。
2. **不许自造算式**：用户没问"差多少"，就别做减法。**量纲不同的数不能直接加减**（300000 公里/秒 与 340 米/秒 相减是错的）。
3. **不许发明工具名**：只用注册过的通道；没注册的不提。
4. **判错存档要看标记**：`裁决: 判错` 的节点可以查，但要标注"这是判错存档，正身见 X"。
5. **同题重跑要一致**：答案变了，就是账记错了，不是"这次更好"。

## 七、最小接通示例（三通道）

```python
import sys; sys.path.insert(0, r"…\_snapshots\ldv-work")
from entry import App
app = App("self")

app.query({"require": ["name=声速"]})                                   # 1 检索：读正文
app.query({"derive": {"运算":"*","左":"name=声速","右":"name=三","字段":"数值"}})  # 2 算：拿算得
app.query({"差距": {"需求": "把到期没还的书催一遍"}})                      # 3 量差距：拿清单
```
