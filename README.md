# 执事（ldv）

**教学驱动的判定内核：规矩写在语料里，能力是教出来的。**
独自办事——量差距、装配、调端口、走推演，每一步带依据、留账；
办不成，给你一张说清缺什么的单子。教过才会，没教就报缺。

**A teaching-driven judgment kernel: capabilities grow from taught
rules, every action cites its source, every gap gets a ticket.**

**当前版本 v0.2.78** · 判据 **1252 条全绿** · 零第三方依赖 · [Apache-2.0](LICENSE)

## 教学途径（它的能力从哪里来）

每条路由的教法定死**七段骨架**：触发 / 动作 / 停手线 / 次数 / 留痕 / 依据 / 可移除。
规矩写在语料节点里，算子是代码里一个 `_xxx_rule()`——**教过才有，没教就报缺单，
不回溯改旧节点**。教法全文：[`docs/路由的教法.md`](docs/路由的教法.md)。

一条真实的教学节点（[`showcase/corpus/规程/conc__522.md`](showcase/corpus/规程/conc__522.md)）：

> **空结果报法规程**：查不到就报查不到，**不许补**。
> 三条规矩：**不改写**——工具说空，交付就说空，不许补一个像样的单号或字段；
> **不合并**——无此记录 / 无权限 / 查询失败三分类各说各的，合并就是把门锁说成屋里没人；
> **不解释代替**——用一句流畅的话盖过空缺，算没答。

**教与不教的对照**是判据的一部分：没教过的运算符，`derive` 当场弃答并出
借算单（算式原样递出去，拿回的值标「外部算得」）；教过《值入形态》之后，
推演边上的值由外面给——**只换值、不换措辞**，换完走不通就明说。

## 与 LLM 的分工

```
LLM  管「怎么问」：读话、定意图、把话翻成方言、组织成回答
执事 管「怎么办」：独自执行、判定对缺、核算代价——每条结论带可复算的依据
```

三条纪律：**不造数**（数值必须来自「算得」）、**不替判**（对缺由执事说）、
**不藏翻译**（方言要交出整句 spec）。桥接契约与密钥环境变量：
[`docs/LLM桥接接口.md`](docs/LLM桥接接口.md) · 参考实现 [`exp/ldv_agent.py`](exp/ldv_agent.py)

**成果展示**：[`showcase/`](showcase/README.md) —— 真实参数、真实回执、真实账本，
拿 `runs/` 里任何一个返回，按依据里的坐标去 `corpus/` 找语料，对得上就是真的。

## 能力总览（全部有判据守着）

| 能力 | 一句话 |
|---|---|
| **分层划分树内核** | 语料 → 划分树；检索**无假阴**是判据（§K8），答案带完备性声明 |
| **教导式路由 ×8** | 装配 / 过程 / 差距 / 建议 / 报缺 / 重发 / 推演 / 值入 |
| **MongoDB 直连** | 自写 BSON + OP_MSG 连 27017（零驱动）；空结果自证、写失败报允许值并挂账 |
| **HTTP 服务壳** | 多租户 / 认证 / 配额 / healthz 与 readyz 分开 / 异步任务 |
| **留痕账本** | dialog · answers · decision · assemble · mongo_ledger——只追加，可审计 |
| **使用学习** | 曝光不算有用、下钻才算、判错只能人授；只排先看哪支，答案集逐字不变 |
| **LLM 桥接** | 五工具契约，密钥走环境变量 |

全通道口径：[`docs/端口与接口标准格式.md`](docs/端口与接口标准格式.md)。
