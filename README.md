# ldv

**分层方向视图** —— 把检索系统的「方向」做成可插拔的分层结构：一层比一层细，
每一层只产出下层表达不出的东西。

**A pluggable layered direction view for retrieval systems.**

> **Layer = Direction** · **Deeper = Finer**
> 输出是**方向**，不是答案。押错了的代价是一次**漏**，而**用本身就是确认**。

**当前版本 v0.1.27** ｜ [历次发布](https://github.com/aic-123/ldv/releases) ｜
**零第三方**（标准库 + 纯内存）｜ [Apache-2.0](LICENSE) ｜
家族位置：`Scaffold` → `arena` → `dce` → **`ldv`（检索方向层）**

代码里那些 `§K8`、`§I4` 一样的号，指的是 [`docs/`](docs/) 里的设计文档 —— **可以逐条对上**。

## 30 秒跑一遍

零依赖、零配置 —— 克隆下来直接跑（**Python 3.13+**）：

```bash
git clone https://github.com/aic-123/ldv.git && cd ldv
python -m ldv.cli a      # 流程 A：在三个方向上各跑一遍检索
```

当场建出三棵方向树，并在每棵树上跑一次检索：

```
四条流程 · 流程 C（构建验收）在 `python -m ldv.run_checks`
本轮跑：A｜方向：['keyset', 'reach', 'sequence']｜维护新项 12｜**不删**（`--remove N` 才跑 B′）

═══ 方向 keyset ═══
  初始：19 个方向（§K2 判空 6），装进 24 项，事件 34 条；待维护 12 项
── 流程 A · 运行 ──
  查询「有 source.kind=其他」→ 命中 0 项｜是=19 否=0 未展开=0｜层=6
    展示 19 个候选（位次 1..19）｜产生记录 19 条｜没给反馈 0 个（**不产记录**：没看见 ≠ 看见了不好）
  终态：19 个方向（§K2 判空 6，叶容量 最大 5 / 平均 2.4），使用记录 55 条；空方向 0（已失效 0）
  账本：初始 34 → B 34（结构 +0） → A 89（展示 +55、**查询时展开** +0） → D 89（自优化**不写账本**）
```

⚠️ **Windows 上先设 utf-8** —— 否则中文输出会 `UnicodeEncodeError`（退出码 1），
而它**和「有检查命中了」长得一模一样**：

```bash

```

## ⚠️ 先说清楚成色

| 项 | 实际情况 |
|---|---|
| 是什么 | 检索系统的**分层方向视图**。输入是项 + 一个插件（三个方向：键集包含 / 锚点可达 / 序列前缀），输出是**一棵方向树** —— 每个方向带 `覆盖`，叶 = 该方向能表达的**分辨率下界** |
| 依赖 | **零第三方**（标准库 + 纯内存，不装任何东西）|
| 测试 | 断言全过（红 0）· 单元测试全过（红 0）· 注入验伪全过（红 0）。⚠️ **跳过 ≠ 通过** —— 判不了就报跳过，不报过 |
| 读数 | **只报过了准入的**（四关：有刻度 / 说的是系统不是环境 / 归因到机制 / 不与别的读数互为函数）。⚠️ **读数不是分** —— 禁合成标量分 / 排序 / 当验收判据 |
| 状态 | ★★ **本版（v0.1.27）一件** —— 两个补跑探针 12 份全齐，读数回填：落盘改成**原子替换 + 写者/读者双侧重试**（Windows 上 `os.replace` 会被读者挡住，实测 **350/400**）。⇒ `run_tests` **607** 条 |
| 不做的 | 曝光模型**在本设计几何上的**标定 / 全局目标函数 / 排序 / 打分 / 匹配；**并发不接进默认路径**（`--locked` 是可选入口）⇒ **系统整体不声称线程安全** |

## 它只回答三句话

    这一层建不建？ 每个方向盖住什么？ 盖住的东西有没有漏？

三句话对应**三种不同性质**的东西 —— **只有第三句能红**：

| 问 | 谁答 | 性质 |
|---|---|---|
| 这一层建不建 | 内核按 §K2 | **度量**（判空次数）—— 判空越多，说明这个方向的形状越贴不上接口 |
| 每个方向盖住什么 | 插件按 §I1 命中 | **允许假阳**（§K8）—— 代价是性能，而性能**会累积** |
| 盖住的东西有没有漏 | 内核按 §I3 代价 分配归属 | **禁止假阴**（§K8）—— 破了就是**正确性**问题 |

### 不对称的那一条（§K8 是承重墙）

    假阳允许 ⇒ 代价是**性能**（会累积）⇒ 必须**计量**
    假阴禁止 ⇒ 破了**正确性**       ⇒ 必须**红**

⇒ 「假阳率」不是质量指标，它是**结构在漏**的读数 —— **所有方向都说「是」，等于没有方向。**

## 它不是什么

- **不是能跑的检索服务** —— 落盘与并发只到「可选壳」那一层 ⇒ **不声称线程安全**
- **不是「自动涌现」** —— 什么算一个方向必须**人声明**（§K9 外生）
- **没有全局目标函数**（§4.3）—— 跨方向的**标量分明令禁止**，`B12` 直接扫源码守着
- **不排序、不打分** —— 排序即推荐，本层不做推荐器（标准见 [`docs/评估标准.md`](docs/评估标准.md)）
- **不做匹配** —— 把一段处境映射到方向是**检索器层**（已实现）的事

⚠️ 每条的理由、边界与实测（含「它和普通检索比好在哪」）见
[**它是怎么长出来的**](docs/它是怎么长出来的.md)。

## 已经证明到哪一步

    ✅ 接口押定：三个「代价形状」完全不同的方向，**一条接口都没动**

       方向          假阳率   §K2判空   叶容量max/avg   方向数   它是什么
       ───────────────────────────────────────────────────────────────────────────────
       A 键集包含     50.1%      7       10 / 2.77      25     粗过滤器：只看节点自己，问得飞快
       B 锚点可达     29.0%      0        1 / 1.00      71     要遍历整张图，但切分点随手可得
       C 序列前缀      0.0%      8       10 / 3.27      16     命中把覆盖**算出来** ⇒ 说不出「是」而实际没有

       ⇒ 同一套 §K2，形状越自然，两个数都越小。**省方向 ⟺ 丢分辨率**

    ✅ 四条流程都能跑（A 运行 / B 维护 / C 构建验收 / D 自优化）+ **B′ 删除**
    ✅ **落盘（P6）与并发（P8）落地** —— 并发壳走 `--locked` 可选入口，**默认路径不锁**
    ✅ **跨进程落盘落地**：临时文件 + `os.replace` + **写者/读者双侧重试**；
       判据六条，其中「失败不留半份」「重试接上了」「重试有界」是**确定性**的
    ✅ **流程 E · 抽象层**：`§A1`–`§A7` 七条判据 + 视图层声明 `§M0`–`§M6`
    ✅ **检索器层（流程 T）**：`T1`–`T8` 八条判据 + 块级结构画像
    ✅ **五套校验在 12 份跨领域语料上跑过**（36 – 82168 项）

⚠️ **覆盖不漏**在 `sequence` 维护路径上**仍破着**（36 项上 16 漏 / 2 对）—— 实测它与
「`滞留 == 0`」是**同一个条件** ⇒ 已**降级**为「有代价的度量 + baseline 守卫」，**如实留着**。

## 5 分钟上手

```bash
python -m ldv.run_checks             # 流程 C：构建验收。三态：红 / 过 / 跳过 —— **跳过不等于通过**
python -m ldv.tests.run_tests        # 单元 / 对照 / 守卫（不需要 pytest）
python -m ldv.tests.test_injections  # 每条检查「基线绿 + 注入红」成对验一次
python -m ldv.tests.test_intake      # 外部语料验收（数据不在 ⇒ 报「跳过」，不报「通过」）

python -m ldv.cli all                # 流程 A+B+D，三个方向都跑
python -m ldv.cli all --remove 12    # 末尾再跑 B′ 删除 12 项
python -m ldv.cli d                  # 只跑流程 D ⇒ **退出码 1**（D 空转，刻意的）

python docs/prior-art/verify_quotes.py \   # 引文核验 —— ⚠️ **必须连调用式一起抄**
  docs/分层方向视图-设计文档.md docs/分层方向视图-抽象层.md \
  docs/分层方向视图-检索器层.md docs/与普通检索系统的质量对照.md
```

**语料在哪**：随仓库那份 36 项在 `ldv/corpus/nodes/`；公开语料放 `_data/<名字>/nodes/`，
用 `LDV_CORPUS=<名字>` 指过去。⚠️ **显式指定却找不到 ⇒ 报错，不回落** ——
回落会让「打错一个字」与「指对了」长得一模一样。

## 目录

```
flow.py          流程的可运行实现（A 运行 / B 维护 / **B′ 删除** / D 自优化）
cli.py           流程的入口 —— 护栏进退出码，度量不进
run_checks.py    流程 C（构建验收）—— B1–B20 + `§A1`–`§A7` + `§M0`–`§M6` + `CL1`–`CL7`
core/
  tri.py          三态。⚠️ 不是 bool —— bool(未展开) 抛异常
  direction.py    方向记录（不可变）+ 事件账本（只追加）
  interfaces.py   §I1–§I7 七个方法的协议 + 运行时守门人
  kernel.py       层 / 秩 / 见证 / 支撑锥 / 按需展开 / 遍历循环 / 倾向记账
  persist.py      落盘/读回 —— **只认 `_children` 为权威边**，派生边现算（§10.2 D 的 P6）
  locking.py      并发 —— 锁的**作用域 = 锥**（§10.2 D 的 P8）。⚠️ 不声称「线程安全」
  selfopt.py      §F0–§F4 自优化。外生项是**只读**的
plugins/          三个方向：keyset（键集包含）/ reach（锚点可达）/ sequence（序列前缀）
corpus/           语料装载。自己写的 front-matter 解析器，形状之外报错不猜
checks/           B1–B20 + `§A1`–`§A7` + `§M0`–`§M6` + `CL1`–`CL7` + 十个度量   **比被检查的内核还大**
tools/            语料接料 + 单变量对照 + `gen_view_spec`（流程 E 的**候选**声明）+ `compare_bm25`（**与普通检索的质量对照**，实跑）
tests/            测试（不需要 pytest）
MEASUREMENTS.md   全部读数，以及每个读数为什么是这样
```

**检查层比被检查的内核大，这是有意的** —— 那不是设计偏好，是代价换来的。
