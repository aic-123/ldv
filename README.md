# ldv

**把语料装成一棵「分层划分树」，然后在树上做检索、推导与反事实推理。**

它做四件事：**记录**（把语料装成划分树）· **检索**（在树上定位候选）·
**推导**（从材料算谓词）· **推理**（找结构矛盾 + 回答「删了会怎样」）。

**定位：一个认知原型** —— 不产内容、只产结构；能把**自己的产物**当材料
（`我` 维度），于是反思与重构是结构里看得见的项，不是内部日志。
定位是**约定**（不是定理）；它蕴含的五条可判承诺见 `§S1`–`§S5`。

**A system that turns a corpus into a hierarchical partition tree you can reason about.**

> **Record · Retrieve · Derive · Reason**
> 四层都只产出**结构**，不产出答案。判错的代价是一次**漏**，而**用本身就是确认**。
>

## 30 秒跑一遍

零依赖、零配置 —— 克隆下来直接跑（**Python 3.13+**）：

```bash
git clone https://github.com/aic-123/ldv.git && cd ldv
python -m ldv.cli a      # 流程 A：在三个插件上各跑一遍检索
```

当场建出三棵划分树，并在每棵树上跑一次检索：

```
四条流程 · 流程 C（构建验收）在 `python -m ldv.run_checks`
本轮跑：A｜方向：['keyset', 'reach', 'sequence']｜维护新项 12｜**不删**（`--remove N` 才跑 B′）

═══ 方向 keyset ═══
  初始：19 个方向（§K2 判空 6），装进 24 项，事件 34 条；待维护 12 项
── 流程 A · 运行 ──
  查询「有 source.kind=其他」→ 命中 0 项｜是=19 否=0 未展开=0｜层=6
    展示 19 个候选（位次 1..19）｜产生记录 19 条｜没给反馈 0 个（**不产记录**：没看见 ≠ 看见了不好）
  终态：19 个方向（§K2 判空 6，叶容量 最大 5 / 平均 2.4），使用记录 55 条；空方向 0（已失效 0）
  账本：初始 34 → B 34（结构 +0） → A 89（展示 +55、**查询时展开** +0） → D 89（自优化**不写账本**）
```

（上面这段是**真实输出**，没删改：`方向` = 划分单元，`判空` = 无法分裂，
`叶容量` = 叶子大小，`账本` = 追加式事件日志。）

## 内核：它只回答三个问题

最小内核是一棵**分层划分树**（`ldv/core/` + `ldv/plugins/`）。
三个问题都是**结构**问题，不问内容：

    这个节点要不要继续分裂？ 它覆盖哪些项？ 覆盖有没有漏？

三者对应**三种不同性质**的东西 —— **只有第三个能红**：

| 问题 | 谁答 | 性质 |
|---|---|---|
| 要不要继续分裂 | 内核，按 `§K2` | **读数**（无法分裂的次数）—— 次数越多，说明这个谓词的形状越贴不上接口 |
| 覆盖哪些项 | 插件，按 `§I1` 命中 | **允许假阳**（`§K8`）—— 代价是性能，而性能**会累积** |
| 覆盖有没有漏 | 内核，按 `§I3` 的**代价归属** | **禁止假阴**（`§K8`）—— 破了就是**正确性**问题 |

### 不对称的那一条（`§K8` 是承重墙）

    假阳允许 ⇒ 代价是**性能**（会累积）⇒ 必须**计量**
    假阴禁止 ⇒ 破了**正确性**       ⇒ 必须**红**

⇒ 「假阳率」不是质量指标，它是**这个划分在漏**的读数 ——
**所有单元都说「是」，等于没有划分。**

## 在这个内核之上

内核之外还有四层。它们**共用同一条红线**（见下一节），
也共用同一套判据体系（`run_checks` 97 断言 / `run_tests` **844** 条 / 注入 71 条）：

| 层 | 做什么 | 一句话判据 |
|---|---|---|
| **① 记录** | 把语料装成划分树（内核 + 三个插件） | 假阴 0（`B1`） |
| **② 检索** | 用结构决定先看哪一片（流程 T，`T1`–`T8`） | 命中把覆盖**算出来** |
| **③ 推导** | 从材料**推导谓词**（`--predicates`）：规则外生、参数内生 | 同材料两次谓词**逐字相同** |
| **④ 推理** | **反思**（矛盾清单，只调展开顺序）+ **影响分析**（删了会怎样） | 预测与实测**一致** |

**基础设施**（不改变任何结构，所以默认关闭、各有判据）：

| 件 | 是什么 | 实测 |
|---|---|---|
| **缓冲区** | 谓词 `候选/采用/拒收` 三段 + 记忆 `_staging/`，判据自动筛选 | `ext-coauth` 拦下 2 条「切不开」的谓词 |
| **记忆分层** | 短期 = 进程内缓存；长期 = 跨进程派生索引（`--index`） | 大语料装载 **9.3×**（冷启动 ≈99×） |
| **组合谓词** | 复杂度 ≤ K 的合取**与单谓词共用预算**、自动命名（键名就是合取表达式）；`> K` 的进「待命名」只是**提示**，不阻塞 | 实测 5 份语料 **2 份**上组合赢预算（mini 0.492 / bitcoin 0.472）；但**结构收益 0**（两项强相关 ⇒ 与单项同一个切分），已加独立性判据把冗余的挡掉 |

## 它不是什么

- **不是能跑的检索服务** —— 落盘与并发只到「可选壳」那一层 ⇒ **不声称线程安全**
- **不是「自动涌现」** —— 什么算一个划分单元必须**人声明**（`§K9` 外生）。
  谓词推导**只推导参数**（切分点从材料算），**不推导规则**（按什么量分档是人写的）
- **没有全局目标函数**（`§4.3`）—— 跨单元的**标量分明令禁止**，`B12` 直接扫源码守着
- **不排序、不打分** —— 排序即推荐，本层不做推荐器（标准见 [`docs/评估标准.md`](docs/评估标准.md)）
- **不做语义推理** —— 「A **意味着** B」要理解内容 ⇒ 撞「禁止模型代填」。
  它的推理是**结构**的：包含、可达、递归分割、**反事实**（删了会怎样）
- **不是「越用越懂你」** —— 使用记录只调**内生**的展开优先级，且**不跨会话累积**；
  什么算一个方向**永远不学**。逐处标记见下节「学习」
- **不做匹配** —— 把一段处境映射到划分单元，是**检索层**（已实现）的事

⚠️ 每条的理由、边界与实测（含「它和普通检索比好在哪」）见
[**它是怎么长出来的**](docs/它是怎么长出来的.md)。

## 学习：哪里不学、为什么，哪里学、学到哪

这张表是**定位的一部分**，不是免责声明。「不学」有几种完全不同的原因，
混在一起说，读者会读成「做不到」：

| 位置 | 有没有学习 | 是哪一种 | 依据 / 替代机制 |
|---|---|---|---|
| **什么算一个方向**（方向函数、维度、谓词规则） | 不学 | **设计：外生项只能人声明** | `§K9`；`B14` 扫源码守「自优化不许改外生项」；断言 `§D1` 外生准入 |
| **跨方向的评分 / 排序** | 不存在 | **没有位置** —— 不是学不了，是不放这个东西 | `B12` + 协议禁词 `score / weight / priority / rating` |
| **内生的局部代价 / 层内展开优先级** | **学** | **设计：学，但只在这里** | 流程 D（F0–F4）：使用记录 → 倾向权重 → 更新 `expand_priority` / `penalty_scale` |
| **使用记录本身** | 记录，不算学习 | **设计：记录不改结构** | 记录不写账本（「D 自优化不写账本」）；`§K6` 无信号 ≠ 负信号 |
| **解析缓存** | 不学 | **设计：纯函数缓存** | key 带 `mtime`，文件一变就失效 ⇒ 缓存 ≠ 学习 |
| **使用者入口**（`entry.py` 的 query / drill） | **学** | **设计：已接线，但只影响呈现次序** | **两段通道**：query 把「摆了哪些支」写进缓冲（`usage/_staging/`，**不算有用**，有界 50 批、暂定值）；drill 才 `promote` 成 `outcome = +1`。记录落 `<语料>/usage/*.md`、**不进 `nodes`**；下次启动读回，只排「先看哪一支」——`answer_ids` / `n_answer` / `n_branches` 逐字不变（判据 `[接入]` 八条 + 探针 `evidence/_probe_usage_wiring.py` 的 `W1`–`W10`） |

三条要说清的：

1. **「没有学习能力」这一栏是空的。** 表里每一处「不学」都指明了替代机制或边界，
   没有一处是「想做但做不到」。⇒ 这个项目**不存在「学不会」**，只存在「不在这里学」。
2. **学的东西跨会话累积，但只累积到「呈现次序」为止。** 使用记录落在
   `<语料>/usage/`，下次启动读回并折算成倾向；它只决定**先说哪一支**，
   `answer_ids` / `n_answer` / `n_branches` 逐字不变（探针 `W5` 守这条）。
   所以「越用越**顺手**」成立，「越用越**懂**」不成立 —— 什么算一个方向仍然永远不学。
   而且**只有下钻过的支才算数**：查询只把「摆了哪些支」写进缓冲，被摆出来只是曝光。
   清空：`python -m ldv.tools.usage_store clear <语料目录>`，清完次序回默认。
3. **为什么「什么算一个方向」永远不学。** 一旦让使用记录决定划分，会同时失去两样东西：
   **可复现性**（同材料、不同历史 ⇒ 不同树）与**可解释性**（说不清这个方向为什么存在），
   而且是**很久以后才发现**，那时已经没法回溯。这就是 `F3` 存在的理由。

**动机（显著性三档）**：反思层把待办按**后果**分三档 ——
**必须**（结构矛盾、**根覆盖之外** ⇒ 结论可能错）/ **可延后**（切不开、待展开、**滞留** ⇒ 对但不全）/ **可忽略**（切了白切、已展开，且**不枚举**）；**档内**才按成员数定序。
★ 账本里的 `stayed`（滞留）与 `out_of_scope`（根覆盖之外）**也进清单** —— 之前只收 矛盾/展开失败/待展开，账本记着而反思层不看，那就是漏。
不是分数（有序等级），且动机只到「提问」，不加维度（`§D1`）。
完整通路「发现 → 提问 → 拍板 → 实施 → 验证」见
[`docs/谓词推导与反思层.md`](docs/谓词推导与反思层.md) §11。

### 两层记忆与遗忘

| 层 | 存在哪 | 界面表现 | 遗忘方式 |
|---|---|---|---|
| **短期显性记忆** | `usage/_staging/`（一批一文件） | **显式提示**：「这批还剩 N 支待看」 | 容量淘汰最旧（50 批，**暂定值**） |
| **长期隐性记忆（稳定区）** | `usage/*.md`（一条一文件） | **不再逐条呈现**，只体现在 `ordered_by` | **降权**（半衰期 30 天，**暂定值**），**记录永不删** |

★ **遗忘发生在计算上，不发生在存储上。** 记录是账本，只追加；
衰减因子 `0.5 ** (年龄 / 半衰期)` 只在算倾向时乘进去。

⇒ 老经验影响力变小，但任何时候都能回答「它曾经学过什么」；
改半衰期就能「重新记起来」（可回退）；删记录只能 `clear`。

实测（`evidence/_probe_forgetting.py`，7 条判据）：一条 300 天前的记录，
倾向 **1.0000 → 0.0010**（10 个半衰期），记录**仍是 1 条**；
答案集合与支数**逐字不变**。

⚠️ **倾向是「累计证据」，不是「平均值」** —— 加权平均里 `w` 会被约掉，
单条老记录和单条新记录的均值一样（实测第一版就是「新 1.0000 → 旧 1.0000」）。
累计才对：重复证据累加（巩固），老证据衰减（遗忘）。

⚠️ 缺时间戳的记录**不衰减**（w = 1.0）—— 不知道时间既不能当「很老」，也不能当「很新」。

⚠️ 会话内 drill **不会**立刻改变后续查询的次序：`_tendency` 在启动时算，
巩固是**跨会话**的事（这也是「长期隐性」的含义）。

⚠️ 如果哪天某一处从「设计上不学」变成「想做但做不到」，那要记成**缺陷**，
不许继续挂在「设计」名下 —— 两者的区别就是这张表存在的意义。

## 5 分钟上手

```bash
python -m ldv.run_checks             # 流程 C：构建验收。三值：红 / 过 / 跳过 —— **跳过不等于通过**
python -m ldv.tests.run_tests        # 单元 / 对照 / 守卫（不需要 pytest）
python -m ldv.tests.test_injections  # 每条检查「基线绿 + 注入红」成对验一次
python -m ldv.tests.test_intake      # 外部语料验收（数据不在 ⇒ 报「跳过」，不报「通过」）

python -m ldv.cli all                # 流程 A+B+D，三个插件都跑
python -m ldv.cli all --remove 12    # 末尾再跑 B′ 删除 12 项
python -m ldv.cli d                  # 只跑流程 D ⇒ **退出码 1**（D 空转，刻意的）

python docs/prior-art/verify_quotes.py \   # 引文核验 —— ⚠️ **必须连调用式一起抄**
  docs/分层方向视图-设计文档.md docs/分层方向视图-抽象层.md \
  docs/分层方向视图-检索器层.md docs/与普通检索系统的质量对照.md
```

**语料在哪**：随仓库那份 36 项在 `ldv/corpus/nodes/`；公开语料放 `_data/<名字>/nodes/`，
用 `LDV_CORPUS=<名字>` 指过去。⚠️ **显式指定却找不到 ⇒ 报错，不回落** ——
回落会让「打错一个字」与「指对了」长得一模一样。

> ⚠️ **随仓库的 36 项是演示语料，且 36/36 都是 `filled_by: 模型(...)`** ——
> 它的作用是让 clone 之后能跑起来，**不代表任何真实材料**。
>
> 这不与「不产内容」矛盾，但两件事必须分清：
>
> | | 指什么 | 谁产 |
> |---|---|---|
> | **不产内容** | **系统运行时**的输出可指回材料（§S1） | 系统**不**产 |
> | **演示语料** | 预先填好的 36 个节点（含正文） | 人 / 模型**预先**填，逐项留痕 |
>
> `filled_by` 就是那条留痕：**允许填，但必须写明谁填的**。真实语料在 `_data/`（不进仓库），
> 那才是「可指回材料」的对象。
