# ldv

**一套把语料变成可推理结构的系统。**
它做四件事：**记录**（把语料装成方向树）· **检索**（流程 T）·
**推导**（从材料算出谓词）· **推理**（找结构矛盾 + 回答「删了会怎样」）。

**A system that turns a corpus into a structure you can reason about.**

> **Record · Retrieve · Derive · Reason**
> 四层都只产**结构**，不产答案。押错了的代价是一次**漏**，而**用本身就是确认**。
>
> 它的**内核**是**分层方向视图** —— 把「方向」做成可插拔的分层结构：
> 一层比一层细，每一层只产出下层表达不出的东西。**Layer = Direction** · **Deeper = Finer**

**当前版本 v0.1.30** ｜ [历次发布](https://github.com/aic-123/ldv/releases) ｜
**零第三方**（标准库 + 纯内存）｜ [Apache-2.0](LICENSE) ｜
家族位置：`Scaffold` → `arena` → `dce` → **`ldv`（结构层：记录 / 检索 / 推导 / 推理）**

代码里那些 `§K8`、`§I4` 一样的号，指的是 [`docs/`](docs/) 里的设计文档 —— **可以逐条对上**。

## 30 秒跑一遍

零依赖、零配置 —— 克隆下来直接跑（**Python 3.13+**）：

```bash
git clone https://github.com/aic-123/ldv.git && cd ldv
python -m ldv.cli a      # 流程 A：在三个方向上各跑一遍检索
```

当场建出三棵方向树，并在每棵树上跑一次检索：

```
四条流程 · 流程 C（构建验收）在 `python -m ldv.run_checks`
本轮跑：A｜方向：['keyset', 'reach', 'sequence']｜维护新项 12｜**不删**（`--remove N` 才跑 B′）

═══ 方向 keyset ═══
  初始：19 个方向（§K2 判空 6），装进 24 项，事件 34 条；待维护 12 项
── 流程 A · 运行 ──
  查询「有 source.kind=其他」→ 命中 0 项｜是=19 否=0 未展开=0｜层=6
    展示 19 个候选（位次 1..19）｜产生记录 19 条｜没给反馈 0 个（**不产记录**：没看见 ≠ 看见了不好）
  终态：19 个方向（§K2 判空 6，叶容量 最大 5 / 平均 2.4），使用记录 55 条；空方向 0（已失效 0）
  账本：初始 34 → B 34（结构 +0） → A 89（展示 +55、**查询时展开** +0） → D 89（自优化**不写账本**）
```

## 内核：它只回答三句话

这个系统的最小内核是**一棵分层方向树**（`ldv/core/` + `ldv/plugins/`）。
内核只回答三句话 —— 它们都是**结构**的问题，不问内容：

    这一层建不建？ 每个方向盖住什么？ 盖住的东西有没有漏？

三句话对应**三种不同性质**的东西 —— **只有第三句能红**：

| 问 | 谁答 | 性质 |
|---|---|---|
| 这一层建不建 | 内核按 §K2 | **度量**（判空次数）—— 判空越多，说明这个方向的形状越贴不上接口 |
| 每个方向盖住什么 | 插件按 §I1 命中 | **允许假阳**（§K8）—— 代价是性能，而性能**会累积** |
| 盖住的东西有没有漏 | 内核按 §I3 代价 分配归属 | **禁止假阴**（§K8）—— 破了就是**正确性**问题 |

### 不对称的那一条（§K8 是承重墙）

    假阳允许 ⇒ 代价是**性能**（会累积）⇒ 必须**计量**
    假阴禁止 ⇒ 破了**正确性**       ⇒ 必须**红**

⇒ 「假阳率」不是质量指标，它是**结构在漏**的读数 —— **所有方向都说「是」，等于没有方向。**

## 在这个内核之上

内核之外，系统还有四层。它们**共用同一条红线**（见下一节），
也共用同一套判据体系（`run_checks` 97 断言 / `run_tests` 662 条 / 注入 71 条）：

| 层 | 做什么 | 一句话判据 |
|---|---|---|
| **① 记录** | 把语料装成方向树（内核 + 三个插件） | 假阴 0（`B1`） |
| **② 检索** | 用那份认识决定先看哪一带（流程 T，`T1`–`T8`） | 命中把覆盖**算出来** |
| **③ 推导** | 从材料**推导谓词**（`--predicates`）：规则外生、参数内生 | 同材料两次谓词**逐字相同** |
| **④ 推理** | **反思**（矛盾清单，只调展开顺序）+ **影响分析**（删了会怎样） | 预测与实测**一致** |

**基础设施**（不改变任何结构，所以默认关闭、各有判据）：

| 件 | 是什么 | 实测 |
|---|---|---|
| **缓冲区** | 谓词 `候选/采用/拒收` 三段 + 记忆 `_staging/`，判据自动筛选 | `ext-coauth` 拦下 2 条「切不开」的谓词 |
| **记忆分层** | 短期 = 进程内缓存；长期 = 跨进程派生索引（`--index`） | 大语料装载 **9.3×**（冷启动 ≈99×） |
| **组合谓词** | 复杂度 ≤ K 的合取**与单谓词共用预算**、自动命名（键名就是合取表达式）；`> K` 的进「待命名」只是**提示**，不阻塞 | 实测 5 份语料 **2 份**上组合赢预算（mini 0.492 / bitcoin 0.472）；但**结构收益 0**（两项强相关 ⇒ 与单项同一个切分），已加独立性判据把冗余的挡掉 |

⚠️ 四层**不共享一个「目标」** —— 它们各自有各自的判据，互不充当打分。
设计、边界与全部实测见 [谓词推导 · 反思层 · 记忆分层](docs/谓词推导与反思层.md)。

## 它不是什么

- **不是能跑的检索服务** —— 落盘与并发只到「可选壳」那一层 ⇒ **不声称线程安全**
- **不是「自动涌现」** —— 什么算一个方向必须**人声明**（§K9 外生）。
  谓词推导**只推导参数**（切分点从材料算），**不推导规则**（按什么量分档是人写的）
- **没有全局目标函数**（§4.3）—— 跨方向的**标量分明令禁止**，`B12` 直接扫源码守着
- **不排序、不打分** —— 排序即推荐，本层不做推荐器（标准见 [`docs/评估标准.md`](docs/评估标准.md)）
- **不做语义推理** —— 「A **意味着** B」要理解内容 ⇒ 撞「禁止模型代填」。
  它的推理是**结构**的：包含、可达、递归分割、**反事实**（删了会怎样）
- **不做匹配** —— 把一段处境映射到方向是**检索器层**（已实现）的事

⚠️ 每条的理由、边界与实测（含「它和普通检索比好在哪」）见
[**它是怎么长出来的**](docs/它是怎么长出来的.md)。

python -m ldv.cli all --remove 12    # 末尾再跑 B′ 删除 12 项
python -m ldv.cli d                  # 只跑流程 D ⇒ **退出码 1**（D 空转，刻意的）

## 证据在哪 —— **不是宣称，是实体**

文档里每一处「实测 / 留档」的引用都指向 `evidence/` 下的文件：

| 文件 | 是什么 |
|---|---|
| `evidence/INDEX.md` | **142 个证据文件**，每个都列出「被哪份文档引用」 |
| `evidence/quotes-index.md` | **310 条引文** → 出自哪个源档 + 最低覆盖比（**不含版权正文**） |

⚠️ `sources/` 里是 45 MB 版权论文，**不进仓库** —— 所以引文侧给的是
